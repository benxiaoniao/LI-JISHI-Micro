# 砾（Micro Core v0）语言卡

> 本文件由 `micc --langcard` 生成，不要手改。
> 机器可读版本：[spec/langcard.json](../spec/langcard.json)。
> 规范来源：`compiler/src/opcodes.rs`、`compiler/src/lexer.rs`、`runtime/src/jm_builtin.c`、`compiler/src/native_spec.rs`、`compiler/src/error.rs`、`runtime/src/jm_internal.h`。
>
> 改了任一来源而没重新生成，`micc --check-langcard` 会失败。

## 概览

| 项 | 值 |
|---|---|
| 语言版本 | Micro Core v0 |
| 字节码格式 | JMB v4（魔数 `JMB1`） |
| Native ABI | v1（`JM_NATIVE_ABI_VERSION`） |
| 编译 | `micc 源码.jsh -o 输出.jmb` |
| 运行 | STM32F103C8T6 固件内解释器；脚本堆固件 6 KB |

> 机器可读字段：`bytecode_magic` / `bytecode_version` / `native_abi_version`；`abi_version` 已弃用，仅为旧消费者保留（值等于魔数）。

砾是**中文关键字、缩进式、整数优先**的小语言。它跑在 20 KB RAM 的 MCU 上，整数是 29 位、小数是 Q12 定点；类没有继承，`最后` 和通用模块系统也没有，异常用显式 `抛出` / `尝试` / `捕获`；闭包按值捕获且捕获变量只读；板级硬件能力通过 `导入 模块` 在编译期引入。

## 关键字

可用：令、如果、否则如果、否则、当、循环、次、遍历、在、中断、继续、函数、返回、真、假、空、与、或、非、导入、抛出、尝试、捕获、类、新建、本。

保留但不支持：继承、最终、匹配、情形、枚举、用、断言、超。这些是 v0 明确拒绝的关键字（E103）。

## 词法规则

| 项目 | 规则 |
|---|---|
| 缩进 | 只认半角空格，4 个一级；Tab 或全角空格报 E109 |
| 注释 | `#` 到行尾 |
| 文本 | 双引号、单引号、中文引号都可定界；支持 \n \t \\ \" \' |
| 全角标点 | 代码区的全角标点自动转半角（字符串内部不转） |
| 标识符 | 字母或下划线开头，后接字母/数字/下划线 |
| 整数 | 十进制；带指数报 E102 |
| 小数 | 如 1.5、0.25；小数点后必须有数字，不支持指数（E102） |

## 运算符

优先级从低到高：`或` → `与` → `非` → 比较 → `+ -` → `* / // %` → 一元 `-` → `**` → 调用/下标。

- 二元：`+ - * / // % **`
- 比较：`== != < > <= >=`（可链式，如 `0 <= x < 10`）
- 一元：`-`（仅整数）、`非`

## 语义要点

| 主题 | 规则 |
|---|---|
| 整数 | 29 位有符号：-268435456 .. 268435455；字面量与运算结果越界都报错。 |
| 小数 | Q12 定点：raw = 值 × 4096，值域约 ±524288，精度 1/4096（0.000244）；字面量小数点后必须有数字，不支持指数（E102）。 |
| 加法重载 | `+` 支持 整数/小数相加、文本+文本（拼接）、列表+列表（连接）；其他组合报类型错误。 |
| 除法 | 整数/整数时 `/` 要求整除，否则报 E023；任一操作数是小数时 `/` 返回小数（四舍五入）。`//` 向下取整且返回整数；`%` 结果符号跟随除数。 |
| 幂 | `**` 的指数必须是非负整数；结果按重复乘实现，溢出即报错。 |
| 比较 | `< > <= >=` 支持整数/小数混合按数值比较、文本对文本（按 UTF-8 字节字典序）；`== !=` 对所有类型成立。 |
| 真值 | 假：0、0.0、空、假、未定义、空文本、空列表、空字典、空范围；其余为真（含函数与内建）。 |
| 下标 | 列表/文本支持负下标（-1 是最后一个）；字典按键查找，键不存在报 E_INDEX；文本下标按字符而不是字节。 |
| 原生模块 | `导入 模块` 只能写在模块顶层；导入后模块里的原生函数名才能调用，名字与参数个数在编译期校验（E112/E113/E115）；`.jmb` 仍只带名字，运行期由 native 表绑定。 |
| 绿色任务 | `导入 任务` 后用 `创建(函数)` 起一个无参子任务（根任务之外最多 3 个），`让出()` 主动换出，`延时(毫秒)` 睡到指定时刻；调度是协作式、按槽轮转，不抢占、无优先级。子任务值栈 96 槽、调用帧 24、`尝试` 只有 1 层（第 2 层报 E028）；根任务仍是 512 槽 / 32 帧 / 8 层。 |
| 任务等待 | 带超时的 `队列接收(队, 毫秒)`、`队列发送(队, 值, 毫秒)`、`信号量等待(信号量, 毫秒)` 会先探测一次，失败就只睡 1 tick 再重试，其他任务照常运行；到期仍不成功返回 `空`（接收）或 `假`（发送/信号量）。不带超时的形式仍是普通原生调用。 |
| 作用域 | 函数内的 `令` 是局部槽；内层函数读取外层局部变量时会按值捕获（定义时快照、只读）；未在函数内声明而同名的读取会落到模块级全局。 |
| 函数 | 模块级函数与闭包都是一等值：可以赋值、传参、作为返回值；实参按值传递；形参与实参个数必须一致；调用层数上限 32。 |
| 闭包 | 内层函数读取外层局部变量即按值捕获（定义那一刻的快照，之后外层再改也不影响）；捕获变量只读（赋值报 E117），不能在函数里捕获自己的名字（E117）；单个函数捕获上限 255（E116）。 |
| 字符串 | 单引号、双引号、中文引号都可定界；反斜杠转义支持 \n \t \\ \" \'；文本按 UTF-8 存。 |
| 字典键 | 键必须是整数/文本/空/真/假这类不可变值；列表、字典、函数、实例不能当键。 |
| 类 | `类` 只能写在模块顶层，类名全局唯一；类体只允许字段（`令 名 = 默认值`，默认值必填且不能引用 `本`）与方法。`新建 C(...)` 调用构造：有 `初始化` 时实参个数必须与它一致，否则只能零实参；`初始化` 里禁止 `返回`，构造结果固定是实例本身。方法内 `本` 是只读绑定（不能 `本 = ...`），`本.字段` 读写与 `对象.字段` 相同。没有继承、没有虚分派：字段和方法都在运行期按名字在类的单层表里查找（结构化多态）。未声明字段/方法报 E035/E037，对非实例取成员报 E036；`本.未知` 与 `本.方法` 当值取是编译期 E122/E123。 |
| 实例 | 实例是普通堆对象：可进列表/字典值、可 `抛出` 并被 `捕获`、可被闭包捕获（含捕获 `本`）；相等比较按身份；`长度`/下标/遍历不适用；native 只能把实例当入参透传，不能构造或返回。 |
| 迭代 | 可遍历：列表、文本（按字符）、字典（按键）、范围。 |
| 异常 | `抛出 表达式` 抛任意值；`尝试: ... 捕获 名字: ...`（或匿名 `捕获:`）在同一函数内捕获。只有显式 `抛出` 可捕获：除零（E007）、堆耗尽（E017）等 VM 故障与原生错误（E030/E031/E033）一律终止，不能被 `捕获` 拦下。没有 `最后`，一个 `尝试` 只能跟一个 `捕获`。 |
| 异常传播 | 抛出后按调用栈向外找最近的 `捕获`；展开时释放被跳过帧的局部槽（含闭包捕获槽）与操作数临时值，抛出值引用计数平衡。到最外层仍未捕获则 `jm_run` 返回 -1，错误为 `错误[E027] 未捕获的异常：<值>`。`返回`/`中断`/`继续` 离开 `尝试` 时都会先结束该层记录。 |
| 捕获变量 | `捕获 名字` 绑定的名字是当前作用域的普通可写变量（函数内为局部槽，模块顶层为全局）；`捕获:` 不绑定名字，丢弃抛出值。 |
| 内存 | 脚本对象都放在固定堆里（固件默认 6 KB）；闭包、容器与实例都按引用计数释放（实例释放时连带释放全部字段），但相互引用成环时 rc 不归零，这块堆不会回收（没有 GC，接受环引用泄漏），反复创建最终报 E_OOM；其余堆满也报 E_OOM，不会崩溃。单个实例带块头占 16+4×字段数 字节。 |

## 硬限制

| 项目 | 上限 |
|---|---|
| 整数范围 | -268435456 .. 268435455（29 位） |
| 小数范围/精度 | 约 ±524288，精度 1/4096（Q12 定点） |
| 名字/常量 | 各 255 个 |
| 函数 | 255 个 |
| 局部变量/函数 | 255 个 |
| 实参/形参 | 各 255 个 |
| 闭包捕获/函数 | 255 个（E116） |
| 列表元素/字典项 | 各 255 个（字面量编译期） |
| 调用层数 | 32 层（JM_MAX_FRAMES） |
| 尝试嵌套 | 8 层（JM_MAX_TRY_DEPTH，超过报 E028） |
| 绿色任务 | 根任务 + 最多 3 个子任务（`创建` 第 4 次报 E038） |
| 子任务限制 | 值栈 96 槽、调用帧 24、`尝试` 只有 1 层（超过报 E028） |
| 未捕获异常显示 | 固定 64 B 缓冲（60 B 正文 + 3 B「…」 + NUL）；正文放不下就截断并以「…」结尾，不会静默丢弃 |
| 类 | 255 个；每类字段 255 个、方法 255 个 |
| 值栈 | 512 槽（JM_STACK_SLOTS） |
| 脚本堆 | 固件 6 KB / 宿主默认 12 KB |
| 字节码 | 单个函数 <64 KB，整包 <64 KB |

## 内建 API

内建函数直接可用，不需要 `导入`；`导入` 只用于板级原生模块（见下一节）。

| 名字 | id | 参数个数 | 说明 |
|---|---|---|---|
| `打印` | 0 | 0..255 | 把参数按显示形式输出，空格分隔，末尾换行；无返回值（空）。 |
| `文本` | 1 | 1..1 | 把任意值转成文本；文本原样返回。 |
| `整数` | 2 | 1..1 | 整数原样返回；小数向零截断；数字文本按十进制解析；其他值报类型错误。 |
| `长度` | 3 | 1..1 | 文本按 UTF-8 字符数、列表按元素数、字典按键数、范围按元素数。 |
| `范围` | 4 | 1..3 | 范围(止) / 范围(起, 止) / 范围(起, 止, 步长)，左闭右开，步长不能为 0。 |
| `类型` | 5 | 1..1 | 返回类型名文本：整数 / 小数 / 文本 / 列表 / 字典 / 范围 / 函数 / 内建 / 实例 / 空 / 真 / 假 / 未定义。 |
| `总和` | 6 | 1..1 | 对列表或范围求和，只接受整数元素。 |
| `最大` | 7 | 1..1 | 列表或范围内的最大整数。 |
| `最小` | 8 | 1..1 | 列表或范围内的最小整数。 |
| `绝对值` | 9 | 1..1 | 整数或小数的绝对值；超出各自范围报溢出。 |
| `小数` | 10 | 1..1 | 整数或小数转成 Q12 定点小数；超出 ±524288 报溢出。 |

## 原生模块（板级）

`导入 模块` 是纯编译期声明，只允许写在模块顶层。导入后，模块里的原生函数名才能调用；名字拼错、参数个数不符、没导入就调用都会在编译期报错（E112/E113/E115），不会拖到运行时 E004。

### 模块 `引脚`（原生表 `f103_board`）

| 函数 | 参数个数 | 说明 |
|---|---|---|
| `引脚写` | 2 | 向指定引脚写电平；v0 只支持引脚 13（PC13），电平 0/1。PC13 低电平点亮。 |
| `引脚读` | 1 | 读指定引脚的输入寄存器值（0/1）；v0 只支持引脚 13（PC13）。 |
| `引脚翻转` | 1 | 读当前电平再取反；v0 只支持引脚 13（PC13）。 |
| `串口写` | 1 | 直接写 USART1（115200 8N1），不换行、不加前缀。 |
| `等待毫秒` | 1 | 忙等 0–60000 毫秒；SysTick 中断仍在跑，调度器不参与。 |

### 模块 `ADC`（原生表 `f103_adc`）

| 函数 | 参数个数 | 说明 |
|---|---|---|
| `ADC初始化` | 0 | 上电并校准 ADC1；PA0–PA7 对应通道 0–7，参考电压 VDDA（3.3V）。 |
| `ADC读` | 1 | 对指定通道（0–7，对应 PA0–PA7）做一次单次转换，返回 0–4095（12 位）。 |

### 模块 `定时器`（原生表 `f103_timer`）

| 函数 | 参数个数 | 说明 |
|---|---|---|
| `定时器初始化` | 0 | 启动 TIM2 为 1 kHz 自由运行计数（16 位，约 65.5 秒回绕）。 |
| `定时器延时` | 1 | 按 TIM2 毫秒计数忙等 0–60000 毫秒；需先调用 定时器初始化。 |
| `定时器计数` | 0 | 返回 TIM2 当前毫秒计数（0–65535，约 65.5 秒回绕）。 |

### 模块 `队列`（原生表 `ipc_queue`）

| 函数 | 参数个数 | 说明 |
|---|---|---|
| `队列创建` | 1 | 队列创建(槽数)，槽数 1–8；返回整数句柄（1 起）。队列项固定是 32 位整数。 |
| `队列发送` | 2..3 | 队列发送(句柄, 整数[, 超时毫秒])；成功返回 真，队列满且超时返回 假。超时默认 0（不等待），范围 0–60000。 |
| `队列接收` | 1..2 | 队列接收(句柄[, 超时毫秒])；有数据返回整数，超时返回 空。超时默认 0。 |
| `队列数量` | 1 | 返回队列里当前的整数条数。 |

### 模块 `信号量`（原生表 `ipc_sem`）

| 函数 | 参数个数 | 说明 |
|---|---|---|
| `信号量创建` | 1..2 | 信号量创建(初值[, 上限])；上限默认 1（二值信号量），两者都在 0–255；返回整数句柄（1 起）。 |
| `信号量等待` | 1..2 | 信号量等待(句柄[, 超时毫秒])；计数大于 0 时减一并返回 真，超时返回 假。超时默认 0。 |

### 模块 `外部中断`（原生表 `f103_exti`）

| 函数 | 参数个数 | 说明 |
|---|---|---|
| `中断绑定` | 2..3 | 中断绑定(引脚, 队列句柄[, 边沿])；引脚 0–4（PA0–PA4 = EXTI0–4），边沿 0=上升（默认）/1=下降/2=双沿。中断里只把引脚号投进队列，不执行砾代码。 |
| `中断触发` | 1 | 中断触发(引脚)，软件触发该 EXTI 线一次（板上写 SWIER，主机直接模拟投递）；已绑定返回 真，未绑定返回 假。 |
| `中断计数` | 1 | 返回该引脚自绑定以来进入中断服务函数的次数。 |
| `中断解除` | 1 | 取消该引脚的绑定并关闭这条 EXTI 线，之后 中断触发 返回 假。 |

单一事实来源：`compiler/src/native_spec.rs`。`micc --emit-native-header` 生成 `runtime/include/jm_native_table.h`，板级与主机端口都展开同一份头；`micc --check-native` 在构建里比对，防止只改一侧。运行期仍由 `jm_native_register` 按名字绑定。

## 语言层任务（绿色）

`导入 任务` 后启动的是 VM 内部的协作式子任务，不走原生表：根任务之外最多 3 个子任务，按槽轮转，不抢占、无优先级。子任务值栈 96 槽、调用帧 24，**`尝试` 只有 1 层**（第 2 层报 E028）；根任务仍是 512 槽 / 32 帧 / 8 层。子任务退出后句柄不回收，`创建` 第 4 次报 E038。

| 函数 | 参数个数 | 说明 |
|---|---|---|
| `创建` | 1 | 创建一个无参子任务，返回任务句柄；最多 3 个子任务 |
| `让出` | 0 | 主动让出，交给下一个就绪任务；没有就绪任务时立即返回 |
| `延时` | 1 | 睡够指定毫秒（0..60000）再继续，不占用 VM |

带超时的等待会先探测一次，失败就只睡 1 tick 再重试，其他任务照常运行；到期仍不成功返回 `空`（接收）或 `假`（发送/信号量）。不带超时的形式仍是普通原生调用。

| 等待函数 | 带超时的实参个数 | 说明 |
|---|---|---|
| `队列接收` | 2 | 带超时：队列空就挂起，到期返回 空 |
| `队列发送` | 3 | 带超时：队列满就挂起，到期返回 假 |
| `信号量等待` | 2 | 带超时：拿不到就挂起，到期返回 假 |

单一事实来源：`compiler/src/vm_spec.rs`（名字与参数个数）和 `runtime/src/jm_vm.c`（语义）。

## 常见错误

### ADC 换算推荐小数：原始 / 4095.0 * 3300

错误写法：

```砾
打印(4094 * 3300.0)
```

正确写法：

```砾
打印(4094 / 4095.0 * 3300)
```

原因：推荐写法是 `原始 / 4095.0 * 3300`，得到 3299.1943 这样的毫伏小数。小数是 Q12 定点，值域约 ±524288，所以必须先除后乘：写成 `原始 * 3300.0` 会得到 13,510,200，直接报 E009 溢出。只有明确要整数毫伏时才改用整数整除 `//`（见下一条）。

### 纯整数场景：结果要整除，否则用 //

错误写法：

```砾
打印(4094 * 3300 / 4095)
```

正确写法：

```砾
打印(4094 * 3300 // 4095)
打印((4094 * 3300 + 2047) // 4095)
```

原因：整数/整数的 `/` 仍是真除法，结果必须整除，否则运行期报 E023（E_DIV_NONINT）：ADC 读 4094 时 `4094 * 3300 / 4095 = 3299.19…` 会在板上中止。确实只要整数毫伏时用 `//` 得 3299；四舍五入加半个除数，`(4094 * 3300 + 2047) // 4095` 得 3299。需要小数就回到上一条的 `4095.0` 写法。

### 缩进必须是 4 个半角空格

错误写法：

```砾
如果 真:
	打印(1)
```

正确写法：

```砾
如果 真:
    打印(1)
```

原因：Tab 与全角空格在缩进位置报 E109；全角标点只在代码里自动转半角。

### 闭包按值捕获，捕获变量只读

错误写法：

```砾
函数 外层():
    令 x = 1
    函数 内层():
        x = 2
        返回 x
```

正确写法：

```砾
函数 外层():
    令 x = 1
    函数 内层():
        返回 x + 1
```

原因：内层函数读到的 `x` 是定义那一刻的快照，之后外层把 `x` 改成 2 也不影响闭包（仍是 1）。给捕获变量赋值报 E117；要改状态就放模块级 `令`，或在函数里用 `令` 新建同名局部变量。

### 只有显式抛出能被捕获

错误写法：

```砾
尝试:
    打印(1 / 0)
捕获 原因:
    打印("捕获了")
```

正确写法：

```砾
如果 除数 == 0:
    抛出 "除数为零"
返回 被除数 / 除数
```

原因：除零（E007）、堆耗尽（E017）这类 VM 故障和原生错误（E030/E031/E033）是终止性的，`捕获` 拦不住，程序会直接以 `运行失败:` 结束。要可恢复的错误就先用条件判断，再显式 `抛出` 并 `捕获`。

### 尝试必须紧跟同层捕获

错误写法：

```砾
尝试:
    抛出 1
打印("继续")
```

正确写法：

```砾
尝试:
    抛出 1
捕获 原因:
    打印(原因)
```

原因：v0 没有 `最后`，也不允许 `尝试` 后没有 `捕获`：缺少同层 `捕获` 报编译错误 E109；单独出现的 `捕获` 同样报 E109。

### 闭包成环会一直占堆（没有 GC）

错误写法：

```砾
令 列表 = []
令 回调 = 造回调(列表)
列表追加(列表, 回调)
```

正确写法：

```砾
只把闭包传给需要它的函数，不让它再被写回自己捕获的容器
```

原因：闭包与它捕获的列表/字典互相引用时，引用计数无法归零，这块堆不会回收；实例字段存回自身（如 `本.自己 = 本`）同样会成环。反复创建这类环会逐步吃满堆，最终运行期报 E017（E_OOM）。当前无 GC，接受环引用泄漏：别在实例字段里存回指自身/父级的引用。

### 类没有继承；方法是“调用”，不是值

错误写法：

```砾
类 子 继承 父:
    函数 读():
        返回 本.值
令 f = c.读
```

正确写法：

```砾
类 计数器:
    令 值 = 0
    函数 读():
        返回 本.值
打印(c.读())
```

原因：`继承` 仍是 v0 不支持的关键字（E103），没有父类与虚分派。方法只能 `对象.方法(...)` 调用；把方法当值取（`令 f = c.读`）拿不到方法，`本.读` 会直接报 E123，普通对象则运行期报 E035。

### 不要给未声明的名字赋值

错误写法：

```砾
计数 = 计数 + 1
```

正确写法：

```砾
令 计数 = 0
计数 = 计数 + 1
```

原因：读取未定义名字会报 E_NAME；先 `令` 再赋值。

### 原生函数要先导入

错误写法：

```砾
引脚写(13, 0)
```

正确写法：

```砾
导入 引脚
引脚写(13, 0)
```

原因：没写 `导入 引脚` 直接调用会报 E113；名字拼错或参数个数不符报 E115，都在编译期，不会等到运行时 E004。

### 列表/文本下标别越界

错误写法：

```砾
令 x = [1, 2][5]
```

正确写法：

```砾
令 x = [1, 2][长度([1, 2]) - 1]
```

原因：越界是运行错误 E_INDEX，不是返回空；负下标从 -1 开始。
