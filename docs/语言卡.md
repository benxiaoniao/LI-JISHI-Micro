# 砾（Micro Core v0）语言卡

> 本文件由 `micc --langcard` 生成，不要手改。
> 机器可读版本：[spec/langcard.json](../spec/langcard.json)。
> 规范来源：`compiler/src/opcodes.rs`、`compiler/src/lexer.rs`、`runtime/src/jm_builtin.c`、`compiler/src/native_spec.rs`、`compiler/src/error.rs`、`runtime/src/jm_internal.h`。
>
> 改了任一来源而没重新生成，`micc --check-langcard` 会失败。

## 概览

| 项 | 值 |
|---|---|
| 语言版本 | Micro Core v0 |
| 字节码 ABI | JMB1 |
| 编译 | `micc 源码.jsh -o 输出.jmb` |
| 运行 | STM32F103C8T6 固件内解释器；脚本堆固件 6 KB |

砾是**中文关键字、缩进式、整数优先**的小语言。它跑在 20 KB RAM 的 MCU 上，整数是 29 位、小数是 Q12 定点；没有类、`最后` 和通用模块系统，异常用显式 `抛出` / `尝试` / `捕获`；闭包按值捕获且捕获变量只读；板级硬件能力通过 `导入 模块` 在编译期引入。

## 关键字

可用：令、如果、否则如果、否则、当、循环、次、遍历、在、中断、继续、函数、返回、真、假、空、与、或、非、导入、抛出、尝试、捕获。

保留但不支持：类、继承、新建、最终、匹配、情形、枚举、用、断言、超。这些是 v0 明确拒绝的关键字（E103）。

## 词法规则

| 项目 | 规则 |
|---|---|
| 缩进 | 只认半角空格，4 个一级；Tab 或全角空格报 E109 |
| 注释 | `#` 到行尾 |
| 文本 | 双引号、单引号、中文引号都可定界；支持 \n \t \\ \" \' |
| 全角标点 | 代码区的全角标点自动转半角（字符串内部不转） |
| 标识符 | 字母或下划线开头，后接字母/数字/下划线 |
| 整数 | 十进制；带指数报 E102 |
| 小数 | 如 1.5、0.25；小数点后必须有数字，不支持指数（E102） |

## 语法速查

| 构造 | 写法 | 例子 |
|---|---|---|
| 声明/赋值 | `令 名字 = 表达式` | `令 数量 = 3` |
| 导入原生模块 | `导入 模块名` | `导入 引脚<br>引脚写(13, 0)` |
| 重新赋值 | `名字 = 表达式` | `数量 = 数量 + 1` |
| 下标赋值 | `容器[下标] = 表达式` | `统计["a"] = 1` |
| 复合赋值 | `左值 += 表达式（-= *= /= //= %= **= 同理）` | `总数 += 2` |
| 条件 | `如果 条件: / 否则如果 条件: / 否则:` | `如果 n > 0:<br>    打印(n)<br>否则:<br>    打印(0)` |
| 当循环 | `当 条件:` | `当 n > 0:<br>    n -= 1` |
| 计数循环 | `循环 N 次:` | `循环 3 次:<br>    打印("砾")` |
| 遍历 | `遍历 名字 在 可迭代:` | `遍历 x 在 范围(5):<br>    打印(x)` |
| 循环控制 | `中断 / 继续` | `循环 5 次:<br>    如果 真:<br>        继续` |
| 函数 | `函数 名字(参数, ...):` | `函数 平方(x):<br>    返回 x * x` |
| 类型标注（仅忽略） | `函数 名字(参数: 类型) -> 类型:` | `函数 加一(x: 整数) -> 整数:<br>    返回 x + 1` |
| 返回 | `返回 [表达式]` | `返回 0` |
| 抛出 | `抛出 表达式` | `抛出 "坏输入"` |
| 尝试/捕获 | `尝试: / 捕获 名字: / 捕获:` | `尝试:<br>    抛出 "坏输入"<br>捕获 原因:<br>    打印(原因)` |
| 调用 | `被调用者(实参, ...)` | `打印(长度(列表))` |
| 下标 | `容器[下标]` | `列表[0]` |
| 列表 | `[元素, ...]` | `[1, 2, 3]` |
| 字典 | `{键: 值, ...}` | `{"a": 1, "b": 2}` |

### 产生式

```text
program := { statement }
statement := import | let | assign | if | while | repeat | foreach | funcdef | return | break | continue | throw | try | expr_stmt
import := '导入' IDENT
let := '令' IDENT '=' expr
assign := lvalue '=' expr | lvalue AUGOP expr
lvalue := IDENT | postfix '[' expr ']'
if := '如果' expr block { '否则如果' expr block } [ '否则' block ]
while := '当' expr block
repeat := '循环' expr [ '次' ] block
foreach := '遍历' IDENT '在' expr block
funcdef := '函数' IDENT '(' [ param { ',' param } ] ')' [ '->' IDENT ] block
param := IDENT [ ':' IDENT ]
return := '返回' [ expr ]
throw := '抛出' expr
try := '尝试' block '捕获' [ IDENT ] block
block := ':' NEWLINE INDENT { statement } DEDENT
expr := or
or := and { '或' and }
and := not { '与' not }
not := '非' not | compare
compare := add { ('=='|'!='|'<'|'>'|'<='|'>=') add }
add := mul { ('+'|'-') mul }
mul := unary { ('*'|'/'|'//'|'%') unary }
unary := '-' unary | power
power := postfix [ '**' unary ]
postfix := primary { '(' args ')' | '[' expr ']' }
primary := INT | STR | '真' | '假' | '空' | IDENT | '(' expr ')' | list | dict
list := '[' [ expr { ',' expr } [ ',' ] ] ']'
dict := '{' [ expr ':' expr { ',' expr ':' expr } [ ',' ] ] '}'
```

## 运算符

优先级从低到高：`或` → `与` → `非` → 比较 → `+ -` → `* / // %` → 一元 `-` → `**` → 调用/下标。

- 二元：`+ - * / // % **`
- 比较：`== != < > <= >=`（可链式，如 `0 <= x < 10`）
- 一元：`-`（仅整数）、`非`

## 语义要点

| 主题 | 规则 |
|---|---|
| 整数 | 29 位有符号：-268435456 .. 268435455；字面量与运算结果越界都报错。 |
| 小数 | Q12 定点：raw = 值 × 4096，值域约 ±524288，精度 1/4096（0.000244）；字面量小数点后必须有数字，不支持指数（E102）。 |
| 加法重载 | `+` 支持 整数/小数相加、文本+文本（拼接）、列表+列表（连接）；其他组合报类型错误。 |
| 除法 | 整数/整数时 `/` 要求整除，否则报 E023；任一操作数是小数时 `/` 返回小数（四舍五入）。`//` 向下取整且返回整数；`%` 结果符号跟随除数。 |
| 幂 | `**` 的指数必须是非负整数；结果按重复乘实现，溢出即报错。 |
| 比较 | `< > <= >=` 支持整数/小数混合按数值比较、文本对文本（按 UTF-8 字节字典序）；`== !=` 对所有类型成立。 |
| 真值 | 假：0、0.0、空、假、未定义、空文本、空列表、空字典、空范围；其余为真（含函数与内建）。 |
| 下标 | 列表/文本支持负下标（-1 是最后一个）；字典按键查找，键不存在报 E_INDEX；文本下标按字符而不是字节。 |
| 原生模块 | `导入 模块` 只能写在模块顶层；导入后模块里的原生函数名才能调用，名字与参数个数在编译期校验（E112/E113/E115）；`.jmb` 仍只带名字，运行期由 native 表绑定。 |
| 作用域 | 函数内的 `令` 是局部槽；内层函数读取外层局部变量时会按值捕获（定义时快照、只读）；未在函数内声明而同名的读取会落到模块级全局。 |
| 函数 | 模块级函数与闭包都是一等值：可以赋值、传参、作为返回值；实参按值传递；形参与实参个数必须一致；调用层数上限 32。 |
| 闭包 | 内层函数读取外层局部变量即按值捕获（定义那一刻的快照，之后外层再改也不影响）；捕获变量只读（赋值报 E117），不能在函数里捕获自己的名字（E117）；单个函数捕获上限 255（E116）。 |
| 字符串 | 单引号、双引号、中文引号都可定界；反斜杠转义支持 \n \t \\ \" \'；文本按 UTF-8 存。 |
| 字典键 | 键必须是整数/文本/空/真/假这类不可变值；列表、字典、函数不能当键。 |
| 迭代 | 可遍历：列表、文本（按字符）、字典（按键）、范围。 |
| 异常 | `抛出 表达式` 抛任意值；`尝试: ... 捕获 名字: ...`（或匿名 `捕获:`）在同一函数内捕获。只有显式 `抛出` 可捕获：除零（E007）、堆耗尽（E017）等 VM 故障与原生错误（E030/E031/E033）一律终止，不能被 `捕获` 拦下。没有 `最后`，一个 `尝试` 只能跟一个 `捕获`。 |
| 异常传播 | 抛出后按调用栈向外找最近的 `捕获`；展开时释放被跳过帧的局部槽（含闭包捕获槽）与操作数临时值，抛出值引用计数平衡。到最外层仍未捕获则 `jm_run` 返回 -1，错误为 `错误[E027] 未捕获的异常：<值>`。`返回`/`中断`/`继续` 离开 `尝试` 时都会先结束该层记录。 |
| 捕获变量 | `捕获 名字` 绑定的名字是当前作用域的普通可写变量（函数内为局部槽，模块顶层为全局）；`捕获:` 不绑定名字，丢弃抛出值。 |
| 内存 | 脚本对象都放在固定堆里（固件默认 6 KB）；闭包按引用计数释放，但闭包与列表/字典互相引用成环时 rc 不归零，这块堆不会回收（没有 GC），反复创建最终报 E_OOM；其余堆满也报 E_OOM，不会崩溃。 |

## 硬限制

| 项目 | 上限 |
|---|---|
| 整数范围 | -268435456 .. 268435455（29 位） |
| 小数范围/精度 | 约 ±524288，精度 1/4096（Q12 定点） |
| 名字/常量 | 各 255 个 |
| 函数 | 255 个 |
| 局部变量/函数 | 255 个 |
| 实参/形参 | 各 255 个 |
| 闭包捕获/函数 | 255 个（E116） |
| 列表元素/字典项 | 各 255 个（字面量编译期） |
| 调用层数 | 32 层（JM_MAX_FRAMES） |
| 尝试嵌套 | 8 层（JM_MAX_TRY_DEPTH，超过报 E028） |
| 未捕获异常显示 | 抛出值最多渲染 64 字节，超出截断 |
| 值栈 | 512 槽（JM_STACK_SLOTS） |
| 脚本堆 | 固件 6 KB / 宿主默认 12 KB |
| 字节码 | 单个函数 <64 KB，整包 <64 KB |

## 内建 API

内建函数直接可用，不需要 `导入`；`导入` 只用于板级原生模块（见下一节）。

| 名字 | id | 参数个数 | 说明 |
|---|---|---|---|
| `打印` | 0 | 0..255 | 把参数按显示形式输出，空格分隔，末尾换行；无返回值（空）。 |
| `文本` | 1 | 1..1 | 把任意值转成文本；文本原样返回。 |
| `整数` | 2 | 1..1 | 整数原样返回；小数向零截断；数字文本按十进制解析；其他值报类型错误。 |
| `长度` | 3 | 1..1 | 文本按 UTF-8 字符数、列表按元素数、字典按键数、范围按元素数。 |
| `范围` | 4 | 1..3 | 范围(止) / 范围(起, 止) / 范围(起, 止, 步长)，左闭右开，步长不能为 0。 |
| `类型` | 5 | 1..1 | 返回类型名文本：整数 / 小数 / 文本 / 列表 / 字典 / 范围 / 函数 / 内建 / 空 / 真 / 假 / 未定义。 |
| `总和` | 6 | 1..1 | 对列表或范围求和，只接受整数元素。 |
| `最大` | 7 | 1..1 | 列表或范围内的最大整数。 |
| `最小` | 8 | 1..1 | 列表或范围内的最小整数。 |
| `绝对值` | 9 | 1..1 | 整数或小数的绝对值；超出各自范围报溢出。 |
| `小数` | 10 | 1..1 | 整数或小数转成 Q12 定点小数；超出 ±524288 报溢出。 |

## 原生模块（板级）

`导入 模块` 是纯编译期声明，只允许写在模块顶层。导入后，模块里的原生函数名才能调用；名字拼错、参数个数不符、没导入就调用都会在编译期报错（E112/E113/E115），不会拖到运行时 E004。

### 模块 `引脚`（原生表 `f103_board`）

| 函数 | 参数个数 | 说明 |
|---|---|---|
| `引脚写` | 2 | 向指定引脚写电平；v0 只支持引脚 13（PC13），电平 0/1。PC13 低电平点亮。 |
| `引脚读` | 1 | 读指定引脚的输入寄存器值（0/1）；v0 只支持引脚 13（PC13）。 |
| `引脚翻转` | 1 | 读当前电平再取反；v0 只支持引脚 13（PC13）。 |
| `串口写` | 1 | 直接写 USART1（115200 8N1），不换行、不加前缀。 |
| `等待毫秒` | 1 | 忙等 0–60000 毫秒；SysTick 中断仍在跑，调度器不参与。 |

### 模块 `ADC`（原生表 `f103_adc`）

| 函数 | 参数个数 | 说明 |
|---|---|---|
| `ADC初始化` | 0 | 上电并校准 ADC1；PA0–PA7 对应通道 0–7，参考电压 VDDA（3.3V）。 |
| `ADC读` | 1 | 对指定通道（0–7，对应 PA0–PA7）做一次单次转换，返回 0–4095（12 位）。 |

### 模块 `定时器`（原生表 `f103_timer`）

| 函数 | 参数个数 | 说明 |
|---|---|---|
| `定时器初始化` | 0 | 启动 TIM2 为 1 kHz 自由运行计数（16 位，约 65.5 秒回绕）。 |
| `定时器延时` | 1 | 按 TIM2 毫秒计数忙等 0–60000 毫秒；需先调用 定时器初始化。 |
| `定时器计数` | 0 | 返回 TIM2 当前毫秒计数（0–65535，约 65.5 秒回绕）。 |

单一事实来源：`compiler/src/native_spec.rs`。`micc --emit-native-header` 生成 `firmware/stm32f103/f103_native_table.h`，C 侧 `JmNativeEntry` 表由该头展开；`micc --check-native` 在构建里比对，防止只改一侧。运行期仍由 `jm_native_register` 按名字绑定。

## 编译期错误码

| 码 | 含义 |
|---|---|
| `E102` | 数字字面量格式错误：不支持指数形式，小数点后必须有数字 |
| `E103` | 使用了 v0 不支持的关键字（类/继承/最终/匹配等） |
| `E104` | 局部变量超过 255 个 |
| `E105` | 名字/常量/列表元素/字典项超过 255 个 |
| `E106` | 函数超过 255 个 |
| `E107` | 不支持参数默认值 |
| `E108` | 不支持属性访问「.」 |
| `E109` | 语法错误：缺少符号/换行/缩进错乱/字符串未闭合/中断继续位置不对 |
| `E110` | 整数超出 29 位范围（-268435456 .. 268435455），或小数超出 Q12 值域（约 ±524288） |
| `E111` | 单个函数或 .jmb 超过 64 KB |
| `E112` | 导入的模块不存在或不可用（v0 有 引脚、ADC、定时器） |
| `E113` | 调用了原生函数但没有先导入它所属的模块 |
| `E114` | 实参超过 255 个 |
| `E115` | 原生函数用法错误：名字拼错、参数个数不符，或当值/左值使用 |
| `E116` | 闭包捕获的变量超过 255 个 |
| `E117` | 闭包捕获的变量只读：不能赋值，也不能在函数里捕获自己的名字 |

| 4 | `E_NAME` | 读到了未定义的名字 |

| 6 | `E_LOCAL` | 局部槽越界或读取未初始化的局部变量 |
| 7 | `E_ZERO_DIV` | 除以零 |
| 8 | `E_ZERO_MOD` | 取模零 |
| 9 | `E_OVERFLOW` | 整数运算溢出 29 位范围 |
| 10 | `E_TYPE` | 类型不支持该运算/比较/调用 |
| 11 | `E_NOT_CALLABLE` | 这个值不能调用 |
| 12 | `E_ARGC` | 实参个数与形参不符 |
| 13 | `E_INDEX_TYPE` | 下标类型不对（如用文本下标列表） |
| 14 | `E_INDEX` | 下标越界或字典里没有这个键 |
| 15 | `E_NOT_ITER` | 这个值不能遍历 |
| 16 | `E_ITER` | 迭代器状态错误 |
| 17 | `E_OOM` | 运行时堆不足 |
| 18 | `E_OBJ` | 对象错误（嵌套太深等） |
| 19 | `E_KEY` | 字典键必须是不可变值（整数/文本/空/真/假） |
| 20 | `E_CODE` | 函数代码对象越界 |

| 25 | `E_IMPORT` | 导入指令保留（编译期导入不生成该指令） |
| 26 | `E_FILE` | 字节码文件损坏或超出边界 |
| 27 | `E_UNCAUGHT` | 未捕获的异常：`抛出` 的值一路传到了最外层（`错误[E027] 未捕获的异常：<值>`） |
| 28 | `E_TRY_DEPTH` | `尝试` 嵌套超过 8 层（运行时固定栈） |
| 29 | `E_TRY_STATE` | `尝试` 栈与当前帧不匹配（字节码不平衡，通常由编译器 bug 引起） |

## 常见错误

### ADC 换算推荐小数：原始 / 4095.0 * 3300

错误写法：

```砾
打印(4094 * 3300.0)
```

正确写法：

```砾
打印(4094 / 4095.0 * 3300)
```

原因：推荐写法是 `原始 / 4095.0 * 3300`，得到 3299.1943 这样的毫伏小数。小数是 Q12 定点，值域约 ±524288，所以必须先除后乘：写成 `原始 * 3300.0` 会得到 13,510,200，直接报 E009 溢出。只有明确要整数毫伏时才改用整数整除 `//`（见下一条）。

### 纯整数场景：结果要整除，否则用 //

错误写法：

```砾
打印(4094 * 3300 / 4095)
```

正确写法：

```砾
打印(4094 * 3300 // 4095)
打印((4094 * 3300 + 2047) // 4095)
```

原因：整数/整数的 `/` 仍是真除法，结果必须整除，否则运行期报 E023（E_DIV_NONINT）：ADC 读 4094 时 `4094 * 3300 / 4095 = 3299.19…` 会在板上中止。确实只要整数毫伏时用 `//` 得 3299；四舍五入加半个除数，`(4094 * 3300 + 2047) // 4095` 得 3299。需要小数就回到上一条的 `4095.0` 写法。

### 缩进必须是 4 个半角空格

错误写法：

```砾
如果 真:
	打印(1)
```

正确写法：

```砾
如果 真:
    打印(1)
```

原因：Tab 与全角空格在缩进位置报 E109；全角标点只在代码里自动转半角。

### 闭包按值捕获，捕获变量只读

错误写法：

```砾
函数 外层():
    令 x = 1
    函数 内层():
        x = 2
        返回 x
```

正确写法：

```砾
函数 外层():
    令 x = 1
    函数 内层():
        返回 x + 1
```

原因：内层函数读到的 `x` 是定义那一刻的快照，之后外层把 `x` 改成 2 也不影响闭包（仍是 1）。给捕获变量赋值报 E117；要改状态就放模块级 `令`，或在函数里用 `令` 新建同名局部变量。

### 只有显式抛出能被捕获

错误写法：

```砾
尝试:
    打印(1 / 0)
捕获 原因:
    打印("捕获了")
```

正确写法：

```砾
如果 除数 == 0:
    抛出 "除数为零"
返回 被除数 / 除数
```

原因：除零（E007）、堆耗尽（E017）这类 VM 故障和原生错误（E030/E031/E033）是终止性的，`捕获` 拦不住，程序会直接以 `运行失败:` 结束。要可恢复的错误就先用条件判断，再显式 `抛出` 并 `捕获`。

### 尝试必须紧跟同层捕获

错误写法：

```砾
尝试:
    抛出 1
打印("继续")
```

正确写法：

```砾
尝试:
    抛出 1
捕获 原因:
    打印(原因)
```

原因：v0 没有 `最后`，也不允许 `尝试` 后没有 `捕获`：缺少同层 `捕获` 报编译错误 E109；单独出现的 `捕获` 同样报 E109。

### 闭包成环会一直占堆（没有 GC）

错误写法：

```砾
令 列表 = []
令 回调 = 造回调(列表)
列表追加(列表, 回调)
```

正确写法：

```砾
只把闭包传给需要它的函数，不让它再被写回自己捕获的容器
```

原因：闭包与它捕获的列表/字典互相引用时，引用计数无法归零，这块堆不会回收；反复创建这类环会逐步吃满堆，最终运行期报 E017（E_OOM）。当前没有标记清扫 GC（计划在 JM14）。

### 没有类和属性访问

错误写法：

```砾
令 s = 对象.名字
```

正确写法：

```砾
令 s = 字典["名字"]
```

原因：`.` 属性访问与 `类/新建` 都被明确拒绝（E108/E103）；用字典加下标。

### 不要给未声明的名字赋值

错误写法：

```砾
计数 = 计数 + 1
```

正确写法：

```砾
令 计数 = 0
计数 = 计数 + 1
```

原因：读取未定义名字会报 E_NAME；先 `令` 再赋值。

### 原生函数要先导入

错误写法：

```砾
引脚写(13, 0)
```

正确写法：

```砾
导入 引脚
引脚写(13, 0)
```

原因：没写 `导入 引脚` 直接调用会报 E113；名字拼错或参数个数不符报 E115，都在编译期，不会等到运行时 E004。

### 列表/文本下标别越界

错误写法：

```砾
令 x = [1, 2][5]
```

正确写法：

```砾
令 x = [1, 2][长度([1, 2]) - 1]
```

原因：越界是运行错误 E_INDEX，不是返回空；负下标从 -1 开始。
