# 砾（Micro Core v0）语言卡

> 本文件由 `micc --langcard` 生成，不要手改。
> 机器可读版本：[spec/langcard.json](../spec/langcard.json)。
> 规范来源：`compiler/src/opcodes.rs`、`compiler/src/lexer.rs`、`runtime/src/jm_builtin.c`、`compiler/src/native_spec.rs`、`compiler/src/error.rs`、`runtime/src/jm_internal.h`。
>
> 改了任一来源而没重新生成，`micc --check-langcard` 会失败。

## 概览

| 项 | 值 |
|---|---|
| 语言版本 | Micro Core v0 |
| 字节码格式 | JMB v5（魔数 `JMB1`） |
| Native ABI | v1（`JM_NATIVE_ABI_VERSION`） |
| 编译 | `micc 源码.jsh -o 输出.jmb` |
| 运行 | STM32F103C8T6 固件内解释器；脚本堆固件 6 KB |

> 机器可读字段：`bytecode_magic` / `bytecode_version` / `native_abi_version`；`abi_version` 已弃用，仅为旧消费者保留（值等于魔数）。

砾是**中文关键字、缩进式、整数优先**的小语言。它跑在 20 KB RAM 的 MCU 上，整数是 29 位、小数是 Q12 定点；类支持单继承（`继承`）与 `超` 显式调父类实现，`最终`、`最后` 和通用模块系统还没有，异常用显式 `抛出` / `尝试` / `捕获`；闭包按值捕获且捕获变量只读；板级硬件能力通过 `导入 模块` 在编译期引入。

## 关键字

可用：令、如果、否则如果、否则、当、循环、次、遍历、在、中断、继续、函数、返回、真、假、空、与、或、非、导入、抛出、尝试、捕获、类、新建、本、枚举、匹配、情形、断言、继承、超。

保留但不支持：最终、用。这些是 v0 明确拒绝的关键字（E103）。

## 词法规则

| 项目 | 规则 |
|---|---|
| 缩进 | 只认半角空格，4 个一级；Tab 或全角空格报 E109 |
| 注释 | `#` 到行尾 |
| 文本 | 双引号、单引号、中文引号都可定界；支持 \n \t \\ \" \' |
| 全角标点 | 代码区的全角标点自动转半角（字符串内部不转） |
| 标识符 | 字母或下划线开头，后接字母/数字/下划线 |
| 整数 | 十进制；带指数报 E102 |
| 小数 | 如 1.5、0.25；小数点后必须有数字，不支持指数（E102） |

## 运算符

优先级从低到高：`或` → `与` → `非` → 比较 → `|` → `^` → `&` → `<< >>` → `+ -` → `* / // %` → 一元 `- ~` → `**` → 调用/下标。

- 二元：`+ - * / // % **`、位运算 `& | ^ << >>`
- 比较：`== != < > <= >=`（可链式，如 `0 <= x < 10`）
- 一元：`-`（仅整数）、`非`、`~`（按位取反，仅整数）

## 语义要点

| 主题 | 规则 |
|---|---|
| 整数 | 29 位有符号：-268435456 .. 268435455；字面量与运算结果越界都报错。 |
| 小数 | Q12 定点：raw = 值 × 4096，值域约 ±524288，精度 1/4096（0.000244）；字面量小数点后必须有数字，不支持指数（E102）。 |
| 加法重载 | `+` 支持 整数/小数相加、文本+文本（拼接）、列表+列表（连接）；其他组合报类型错误。 |
| 除法 | 整数/整数时 `/` 要求整除，否则报 E023；任一操作数是小数时 `/` 返回小数（四舍五入）。`//` 向下取整且返回整数；`%` 结果符号跟随除数。 |
| 幂 | `**` 的指数必须是非负整数；结果按重复乘实现，溢出即报错。 |
| 比较 | `< > <= >=` 支持整数/小数混合按数值比较、文本对文本（按 UTF-8 字节字典序）；`== !=` 对所有类型成立。 |
| 真值 | 假：0、0.0、空、假、未定义、空文本、空列表、空字典、空范围；其余为真（含函数与内建）。 |
| 下标 | 列表/文本支持负下标（-1 是最后一个）；字典按键查找，键不存在报 E_INDEX；文本下标按字符而不是字节。 |
| 原生模块 | `导入 模块` 只能写在模块顶层；导入后模块里的原生函数名才能调用，名字与参数个数在编译期校验（E112/E113/E115）；`.jmb` 仍只带名字，运行期由 native 表绑定。 |
| 绿色任务 | `导入 任务` 后用 `创建(函数)` 起一个无参子任务（根任务之外最多 3 个），`让出()` 主动换出，`延时(毫秒)` 睡到指定时刻；`删除(句柄)` 可取消一个未在运行的任务。调度是协作式、按槽轮转，不抢占、无优先级。子任务值栈 96 槽、调用帧 24、`尝试` 最多 4 层（第 5 层报 E028）；根任务仍是 512 槽 / 32 帧 / 8 层。子任务退出的槽位暂不复用。 |
| 任务等待 | 带超时的 `队列接收(队, 毫秒)`、`队列发送(队, 值, 毫秒)`、`信号量等待(信号量, 毫秒)` 会先探测一次，失败就只睡 1 tick 再重试，其他任务照常运行；到期仍不成功返回 `空`（接收）或 `假`（发送/信号量）。不带超时的形式仍是普通原生调用。 |
| 作用域 | 函数内的 `令` 是局部槽；内层函数读取外层局部变量时会按值捕获（定义时快照、只读）；未在函数内声明而同名的读取会落到模块级全局。 |
| 函数 | 模块级函数与闭包都是一等值：可以赋值、传参、作为返回值；实参按值传递；形参与实参个数必须一致；调用层数上限 32。 |
| 闭包 | 内层函数读取外层局部变量即按值捕获（定义那一刻的快照，之后外层再改也不影响）；捕获变量只读（赋值报 E117），不能在函数里捕获自己的名字（E117）；单个函数捕获上限 255（E116）。 |
| 匿名函数 | `函数(参数): 表达式`（单行）或 `函数(参数):` + 缩进块，本身就是表达式，可以赋给变量、传参、返回、立刻调用 `(函数(x): x + 1)(5)`。它与具名闭包完全同一套机制：按值捕获外层局部变量、捕获变量只读、同样受 255 个捕获上限约束；没有名字，所以不能递归调用自己（要递归就用具名函数）。函数体单行写法也可用在具名函数上：`函数 平方(x): x * x`。 |
| 字符串 | 单引号、双引号、中文引号都可定界；反斜杠转义支持 \n \t \\ \" \'。文本按 UTF-8 存。字符串里的 `{表达式}` 是**文本插值**：编译期展开成 `+` 拼接，并对每个插值自动套 `文本()`（不引入运行期格式化）；字面花括号写 `\{` `\}`（或 `{{` `}}`），单独的 `}` 按字面处理。插值表达式里不要出现右花括号。 |
| 文本库 | 文本函数全部按 **UTF-8 码点**处理、返回新文本，不改原值。`子串(s, 起[, 止])` 左闭右开、可负、越界夹取、起 ≥ 止为空；`查找(s, 子串)` 返回首次出现的码点下标，找不到 -1，空子串返回 0；`替换(s, 旧, 新)` 替换所有不重叠出现，旧为空原样返回；`分割(s, 分隔符)` 返回文本列表，连续分隔符产生空文本，分隔符为空按码点切；`连接(列表[, 分隔符])` 只拼接文本元素（否则 E010）；`去空白` 只去两端 ASCII 空白；`转大写/转小写` 只转 ASCII 字母，中文原样。参数类型不符报 E010，子串下标不是整数报 E013，参数个数不符报 E012。 |
| 列表库 | `追加(列表, 值)` 原地末尾追加；`插入(列表, 下标, 值)` 原地插入到下标前（可负、越界夹取）；两者返回 空。`移除(列表, 下标)` 移走并返回该元素（可负，越界 E014，下标非整数 E013）；名字用「移除」是为了避开任务模块的 `删除(句柄)`。`切片(列表, 起[, 止])` 与 `反转(列表)`、`排序(列表)` 都返回**新列表**，元素按引用共享，不改原列表。`排序` 用稳定插入排序，元素须全为整数/小数（按数值）或全为文本（按 UTF-8 字节序），混类型报 E010。`查找(列表, 值)` 返回首个相等元素的下标，找不到 -1。 |
| 字典库 | `键列表(字典)` 按插入顺序返回键的新列表；`包含(字典, 键)` 返回 真/假；`合并(字典, 字典)` 返回**新字典**（同键以后一个为准，两边都不改）；`移除键(字典, 键)` 删掉并返回值，键不存在返回 空（名字用「移除键」是为了避开任务模块的 `删除`）；`默认值(字典, 键, 默认)` 键存在返回值、否则返回默认。键仍限不可变值，容器/实例当键走 E019。 |
| 字典键 | 键必须是整数/文本/空/真/假这类不可变值；列表、字典、函数、实例不能当键。 |
| 集合 | `集合()` 创建无序去重容器，用 `集合加入/集合有/集合删除` 操作；元素限不可变值（整数/文本/空/真/假/小数），容器、集合与实例报 E019。内部是线性数组：`长度` 可用、`遍历` 按插入顺序、**不支持下标**。打印为 `集合{1, 2}`；相等比较按身份。 |
| 字节 | 字节是不可变**原始字节串**，与文本不同：`长度`、`遍历`、下标都按字节而不是 UTF-8 码点。由 `字节(文本)` 或 `字节(整数列表)` 构造（无字面量，不改 JMB）；`字节取(字节, 下标)` 返回 0..255 整数，`字节文本` 按 UTF-8 拷回文本、**不做合法性校验**。`+` 支持字节+字节拼接；相等按内容逐字节比较；打印为 `字节<00 FF 1A>`。列表元素越界、十六进制非法都报 E010。 |
| 位运算 | `& | ^ << >> ~` 只接受整数（小数/文本/容器报 E010）。按 **32 位补码**计算，结果必须落在 29 位范围 `-268435456..268435455`，否则报 E009——实际上只有 `<<` 会溢出，`& | ^ ~` 不会。移位次数必须是 `0..31`，负数或 ≥32 报 E010；`>>` 是**算术右移**（`-8 >> 1 = -4`），不提供逻辑右移。`~x` 在编译期降级为 `x ^ -1`。位运算整体高于比较：`a & b == c` 等于 `(a & b) == c`。 |
| 类 | `类` 只能写在模块顶层，类名全局唯一；类体只允许字段（`令 名 = 默认值`，默认值必填且不能引用 `本`）与方法。`类 子 继承 父:` 是**单继承**：父类必须写在同一模块里（可以写在子类之后），字段按「父类字段在前」扁平继承、沿父链不能重名；方法同名即覆写，运行期沿父链查找，父方法里的 `本.方法(...)` 会调到子类覆写版本。子类构造先自动执行父类初始化（`LOAD_LOCAL 0 / CALL_INIT 父 0 / POP`），再跑本类字段默认值与 `初始化`；因此**父类 `初始化` 必须零形参**（E140）。`新建 C(...)` 有 `初始化` 时实参个数必须与它一致，否则只能零实参；`初始化` 里禁止 `返回`，构造结果固定是实例本身。方法内 `本` 是只读绑定（不能 `本 = ...`），`本.字段` 读写与 `对象.字段` 相同。`超.方法(...)` 在编译期解析到父类实现（沿父链找同名方法）并静态调用，不再按实例类派发；`超` 只能这样调用，不能当值、不能赋值，也不能写 `超.初始化`（父构造已自动执行）。未声明字段/方法报 E035/E037，对非实例取成员报 E036；`本.未知` 与 `本.方法` 当值取是编译期 E122/E123。继承相关错误 E140，`超` 用法错误 E141，字段总数（含继承）超过 255 报 E105。 |
| 枚举 | `枚举 名字:` 下每行一个成员，可以写显式值 `成员 = 10`（可负）；没写时取**上一个成员的取值 +1**，第一个默认 0，所以 `空闲 / 运行 = 10 / 暂停` 得到 0 / 10 / 11。成员写作 `枚举名.成员`，编译期直接折成整数，不产生运行期对象、不进名字表。枚举名只能写在模块顶层，不能与顶层变量/函数/类、内建函数或原生函数重名（E139）；成员名不能重复、取值也不能重复（E139），取值超出 29 位整数范围报 E110。变量与参数也不能与枚举重名。枚举是**包内私有**的：依赖包里的枚举合并时会改名为 `包名::枚举名`，根包直接引用会报 E128；不同包可以同名。 |
| 匹配 | `匹配 表达式:` 后跟若干 `情形` 分支，模式可以是整数字面量、闭区间 `起..止`（两端都含）、枚举成员，或逗号分隔的多个模式；可选的 `情形 其他:` 必须最后。主体只求值一次，按声明顺序用 `==` 与两次边界比较判定，命中即执行该分支再跳出。语句形式无返回值、不要求覆盖所有取值；分支值与区间不能重复或重叠（E139）。 |
| 匹配表达式 | `匹配` 也可以当表达式：每个分支体是单行表达式，必须有 `情形 其他:` 兜底；命中分支的值放进临时槽后压栈，可直接赋给变量、`返回` 或参与外层表达式。能静态看出的字面量分支必须同类型（整数/小数/文本/布尔/空，混用报 E139），非字面量分支不做静态检查。因为要换行缩进，它只能写在语句级表达式位置（`令`、`返回` 的右边等），不能塞进括号里。 |
| 实例 | 实例是普通堆对象：可进列表/字典值、可 `抛出` 并被 `捕获`、可被闭包捕获（含捕获 `本`）；相等比较按身份；`长度`/下标/遍历不适用；native 只能把实例当入参透传，不能构造或返回。 |
| 迭代 | 可遍历：列表、文本（按字符）、字典（按键）、范围。 |
| 断言 | `断言 条件[, 消息]`：条件为真时什么都不做；为假时抛出消息（省略消息则抛文本 `"断言失败"`）。等价于 `如果 非 条件: 抛出 ...`，因此可被 `尝试`/`捕获` 捕获，未捕获时报 `错误[E027] 未捕获的异常：<消息>`。条件与消息只在需要时求值。编译时加 `--no-assert`（`micc pack` 同）会把整句消除：条件和消息都不求值、不生成字节码。 |
| 异常 | `抛出 表达式` 抛任意值；`尝试: ... 捕获 名字: ...`（或匿名 `捕获:`）在同一函数内捕获。只有显式 `抛出` 可捕获：除零（E007）、堆耗尽（E017）等 VM 故障与原生错误（E030/E031/E033）一律终止，不能被 `捕获` 拦下。没有 `最后`，一个 `尝试` 只能跟一个 `捕获`。 |
| 异常传播 | 抛出后按调用栈向外找最近的 `捕获`；展开时释放被跳过帧的局部槽（含闭包捕获槽）与操作数临时值，抛出值引用计数平衡。到最外层仍未捕获则 `jm_run` 返回 -1，错误为 `错误[E027] 未捕获的异常：<值>`。`返回`/`中断`/`继续` 离开 `尝试` 时都会先结束该层记录。 |
| 捕获变量 | `捕获 名字` 绑定的名字是当前作用域的普通可写变量（函数内为局部槽，模块顶层为全局）；`捕获:` 不绑定名字，丢弃抛出值。 |
| 内存 | 脚本对象都放在固定堆里（固件默认 6 KB）；闭包、容器与实例都按引用计数释放（实例释放时连带释放全部字段），但相互引用成环时 rc 不归零，这块堆不会回收（没有 GC，接受环引用泄漏），反复创建最终报 E_OOM；其余堆满也报 E_OOM，不会崩溃。单个实例带块头占 16+4×字段数 字节。 |

## 语言层任务（绿色）

`导入 任务` 后启动的是 VM 内部的协作式子任务，不走原生表：根任务之外最多 3 个子任务，按槽轮转，不抢占、无优先级。子任务值栈 96 槽、调用帧 24，**`尝试` 最多 4 层**（第 5 层报 E028）；根任务仍是 512 槽 / 32 帧 / 8 层。`删除(句柄)` 可取消未在运行的任务；子任务退出或删除后句柄/槽位暂不回收，`创建` 第 4 次报 E038。

| 函数 | 参数个数 | 说明 |
|---|---|---|
| `创建` | 1 | 创建一个无参子任务，返回任务句柄；最多 3 个子任务 |
| `删除` | 1 | 删除(句柄)：取消一个未在运行的任务（就绪/延时/等待中），释放它的值栈与任务体并返回 真；句柄无效、已结束或指向当前任务返回 假。槽位暂不复用。 |
| `让出` | 0 | 主动让出，交给下一个就绪任务；没有就绪任务时立即返回 |
| `延时` | 1 | 睡够指定毫秒（0..60000）再继续，不占用 VM |

带超时的等待会先探测一次，失败就只睡 1 tick 再重试，其他任务照常运行；到期仍不成功返回 `空`（接收）或 `假`（发送/信号量）。不带超时的形式仍是普通原生调用。

| 等待函数 | 带超时的实参个数 | 说明 |
|---|---|---|
| `队列接收` | 2 | 带超时：队列空就挂起，到期返回 空 |
| `队列发送` | 3 | 带超时：队列满就挂起，到期返回 假 |
| `信号量等待` | 2 | 带超时：拿不到就挂起，到期返回 假 |

单一事实来源：`compiler/src/vm_spec.rs`（名字与参数个数）和 `runtime/src/jm_vm.c`（语义）。

## 常见错误

### ADC 换算推荐小数：原始 / 4095.0 * 3300

错误写法：

```砾
打印(4094 * 3300.0)
```

正确写法：

```砾
打印(4094 / 4095.0 * 3300)
```

原因：推荐写法是 `原始 / 4095.0 * 3300`，得到 3299.1943 这样的毫伏小数。小数是 Q12 定点，值域约 ±524288，所以必须先除后乘：写成 `原始 * 3300.0` 会得到 13,510,200，直接报 E009 溢出。只有明确要整数毫伏时才改用整数整除 `//`（见下一条）。

### 纯整数场景：结果要整除，否则用 //

错误写法：

```砾
打印(4094 * 3300 / 4095)
```

正确写法：

```砾
打印(4094 * 3300 // 4095)
打印((4094 * 3300 + 2047) // 4095)
```

原因：整数/整数的 `/` 仍是真除法，结果必须整除，否则运行期报 E023（E_DIV_NONINT）：ADC 读 4094 时 `4094 * 3300 / 4095 = 3299.19…` 会在板上中止。确实只要整数毫伏时用 `//` 得 3299；四舍五入加半个除数，`(4094 * 3300 + 2047) // 4095` 得 3299。需要小数就回到上一条的 `4095.0` 写法。

### 缩进必须是 4 个半角空格

错误写法：

```砾
如果 真:
	打印(1)
```

正确写法：

```砾
如果 真:
    打印(1)
```

原因：Tab 与全角空格在缩进位置报 E109；全角标点只在代码里自动转半角。

### 闭包按值捕获，捕获变量只读

错误写法：

```砾
函数 外层():
    令 x = 1
    函数 内层():
        x = 2
        返回 x
```

正确写法：

```砾
函数 外层():
    令 x = 1
    函数 内层():
        返回 x + 1
```

原因：内层函数读到的 `x` 是定义那一刻的快照，之后外层把 `x` 改成 2 也不影响闭包（仍是 1）。给捕获变量赋值报 E117；要改状态就放模块级 `令`，或在函数里用 `令` 新建同名局部变量。

### 只有显式抛出能被捕获

错误写法：

```砾
尝试:
    打印(1 / 0)
捕获 原因:
    打印("捕获了")
```

正确写法：

```砾
如果 除数 == 0:
    抛出 "除数为零"
返回 被除数 / 除数
```

原因：除零（E007）、堆耗尽（E017）这类 VM 故障和原生错误（E030/E031/E033）是终止性的，`捕获` 拦不住，程序会直接以 `运行失败:` 结束。要可恢复的错误就先用条件判断，再显式 `抛出` 并 `捕获`。

### 尝试必须紧跟同层捕获

错误写法：

```砾
尝试:
    抛出 1
打印("继续")
```

正确写法：

```砾
尝试:
    抛出 1
捕获 原因:
    打印(原因)
```

原因：v0 没有 `最后`，也不允许 `尝试` 后没有 `捕获`：缺少同层 `捕获` 报编译错误 E109；单独出现的 `捕获` 同样报 E109。

### 闭包成环会一直占堆（没有 GC）

错误写法：

```砾
令 列表 = []
令 回调 = 造回调(列表)
列表追加(列表, 回调)
```

正确写法：

```砾
只把闭包传给需要它的函数，不让它再被写回自己捕获的容器
```

原因：闭包与它捕获的列表/字典互相引用时，引用计数无法归零，这块堆不会回收；实例字段存回自身（如 `本.自己 = 本`）同样会成环。反复创建这类环会逐步吃满堆，最终运行期报 E017（E_OOM）。当前无 GC，接受环引用泄漏：别在实例字段里存回指自身/父级的引用。

### 没有 `最终`；`超` 只能调父类实现，方法是“调用”不是值

错误写法：

```砾
类 子 继承 父:
    函数 读():
        返回 超
令 f = c.读
```

正确写法：

```砾
类 子 继承 父:
    函数 读():
        返回 超.读()
打印(c.读())
```

原因：单继承与 `超` 已经支持（`超` 在编译期解析到父类实现并静态调用），但 `最终`（LI014）仍是 v0 明确拒绝的关键字（E103）：不能禁止继承或覆写。`超` 不能当值、不能赋值、不能写 `超.初始化`；方法只能 `对象.方法(...)` 调用，把方法当值取（`令 f = c.读`）拿不到方法，`本.读` 会直接报 E123，普通对象则运行期报 E035。

### 不要给未声明的名字赋值

错误写法：

```砾
计数 = 计数 + 1
```

正确写法：

```砾
令 计数 = 0
计数 = 计数 + 1
```

原因：读取未定义名字会报 E_NAME；先 `令` 再赋值。

### 原生函数要先导入

错误写法：

```砾
引脚写(13, 0)
```

正确写法：

```砾
导入 引脚
引脚写(13, 0)
```

原因：没写 `导入 引脚` 直接调用会报 E113；名字拼错或参数个数不符报 E115，都在编译期，不会等到运行时 E004。

### 列表/文本下标别越界

错误写法：

```砾
令 x = [1, 2][5]
```

正确写法：

```砾
令 x = [1, 2][长度([1, 2]) - 1]
```

原因：越界是运行错误 E_INDEX，不是返回空；负下标从 -1 开始。
