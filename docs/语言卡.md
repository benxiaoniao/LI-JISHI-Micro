# 砾（Micro Core v0）语言卡

> 本文件由 `micc --langcard` 生成，不要手改。
> 机器可读版本：[spec/langcard.json](../spec/langcard.json)。
> 规范来源：`compiler/src/opcodes.rs`、`compiler/src/lexer.rs`、`runtime/src/jm_builtin.c`、`compiler/src/error.rs`、`runtime/src/jm_internal.h`。
>
> 改了任一来源而没重新生成，`micc --check-langcard` 会失败。

## 概览

| 项 | 值 |
|---|---|
| 语言版本 | Micro Core v0 |
| 字节码 ABI | JMB1 |
| 编译 | `micc 源码.jsh -o 输出.jmb` |
| 运行 | STM32F103C8T6 固件内解释器；脚本堆固件 6 KB |

砾是**中文关键字、缩进式、整数优先**的小语言。它跑在 20 KB RAM 的 MCU 上，所以刻意没有小数、类、闭包和模块导入。

## 关键字

可用：令、如果、否则如果、否则、当、循环、次、遍历、在、中断、继续、函数、返回、真、假、空、与、或、非。

保留但不支持：导入、类、继承、新建、尝试、捕获、最终、抛出、匹配、情形、枚举、用、断言、超。其中 `导入` 是保留字，v0 用到即报 E112；其余是 v0 明确拒绝的关键字（E103）。

## 词法规则

| 项目 | 规则 |
|---|---|
| 缩进 | 只认半角空格，4 个一级；Tab 或全角空格报 E109 |
| 注释 | `#` 到行尾 |
| 文本 | 双引号、单引号、中文引号都可定界；支持 \n \t \\ \" \' |
| 全角标点 | 代码区的全角标点自动转半角（字符串内部不转） |
| 标识符 | 字母或下划线开头，后接字母/数字/下划线 |
| 整数 | 十进制；带小数点或指数报 E102（v0 没有小数） |

## 语法速查

| 构造 | 写法 | 例子 |
|---|---|---|
| 声明/赋值 | `令 名字 = 表达式` | `令 数量 = 3` |
| 重新赋值 | `名字 = 表达式` | `数量 = 数量 + 1` |
| 下标赋值 | `容器[下标] = 表达式` | `统计["a"] = 1` |
| 复合赋值 | `左值 += 表达式（-= *= /= //= %= **= 同理）` | `总数 += 2` |
| 条件 | `如果 条件: / 否则如果 条件: / 否则:` | `如果 n > 0:<br>    打印(n)<br>否则:<br>    打印(0)` |
| 当循环 | `当 条件:` | `当 n > 0:<br>    n -= 1` |
| 计数循环 | `循环 N 次:` | `循环 3 次:<br>    打印("砾")` |
| 遍历 | `遍历 名字 在 可迭代:` | `遍历 x 在 范围(5):<br>    打印(x)` |
| 循环控制 | `中断 / 继续` | `循环 5 次:<br>    如果 真:<br>        继续` |
| 函数 | `函数 名字(参数, ...):` | `函数 平方(x):<br>    返回 x * x` |
| 类型标注（仅忽略） | `函数 名字(参数: 类型) -> 类型:` | `函数 加一(x: 整数) -> 整数:<br>    返回 x + 1` |
| 返回 | `返回 [表达式]` | `返回 0` |
| 调用 | `被调用者(实参, ...)` | `打印(长度(列表))` |
| 下标 | `容器[下标]` | `列表[0]` |
| 列表 | `[元素, ...]` | `[1, 2, 3]` |
| 字典 | `{键: 值, ...}` | `{"a": 1, "b": 2}` |

### 产生式

```text
program := { statement }
statement := let | assign | if | while | repeat | foreach | funcdef | return | break | continue | expr_stmt
let := '令' IDENT '=' expr
assign := lvalue '=' expr | lvalue AUGOP expr
lvalue := IDENT | postfix '[' expr ']'
if := '如果' expr block { '否则如果' expr block } [ '否则' block ]
while := '当' expr block
repeat := '循环' expr [ '次' ] block
foreach := '遍历' IDENT '在' expr block
funcdef := '函数' IDENT '(' [ param { ',' param } ] ')' [ '->' IDENT ] block
param := IDENT [ ':' IDENT ]
return := '返回' [ expr ]
block := ':' NEWLINE INDENT { statement } DEDENT
expr := or
or := and { '或' and }
and := not { '与' not }
not := '非' not | compare
compare := add { ('=='|'!='|'<'|'>'|'<='|'>=') add }
add := mul { ('+'|'-') mul }
mul := unary { ('*'|'/'|'//'|'%') unary }
unary := '-' unary | power
power := postfix [ '**' unary ]
postfix := primary { '(' args ')' | '[' expr ']' }
primary := INT | STR | '真' | '假' | '空' | IDENT | '(' expr ')' | list | dict
list := '[' [ expr { ',' expr } [ ',' ] ] ']'
dict := '{' [ expr ':' expr { ',' expr ':' expr } [ ',' ] ] '}'
```

## 运算符

优先级从低到高：`或` → `与` → `非` → 比较 → `+ -` → `* / // %` → 一元 `-` → `**` → 调用/下标。

- 二元：`+ - * / // % **`
- 比较：`== != < > <= >=`（可链式，如 `0 <= x < 10`）
- 一元：`-`（仅整数）、`非`

## 语义要点

| 主题 | 规则 |
|---|---|
| 整数 | 29 位有符号：-268435456 .. 268435455；字面量与运算结果越界都报错。 |
| 没有小数 | v0 只有整数；带小数点或指数的字面量是编译错误（E102），`/` 不能整除也是运行错误（E_DIV_NONINT）。 |
| 加法重载 | `+` 支持 整数+整数、文本+文本（拼接）、列表+列表（连接）；其他组合报类型错误。 |
| 除法 | `/` 要求整除；`//` 向下取整（负数也向下）；`%` 结果非负（符号跟随除数）。 |
| 幂 | `**` 的指数必须是非负整数，按循环乘实现，溢出即报错。 |
| 比较 | `< > <= >=` 只支持 整数对整数、文本对文本（按 UTF-8 字节字典序）；`== !=` 对所有类型成立。 |
| 真值 | 假：0、空、假、未定义、空文本、空列表、空字典、空范围；其余为真（含函数与内建）。 |
| 下标 | 列表/文本支持负下标（-1 是最后一个）；字典按键查找，键不存在报 E_INDEX；文本下标按字符而不是字节。 |
| 作用域 | 函数内的 `令` 是局部槽；未在函数内声明而同名的读取会落到模块级全局（v0 没有闭包）。 |
| 函数 | 只有模块级函数；实参按值传递；形参与实参个数必须一致；调用层数上限 32。 |
| 字符串 | 单引号、双引号、中文引号都可定界；反斜杠转义支持 \n \t \\ \" \'；文本按 UTF-8 存。 |
| 字典键 | 键必须是整数/文本/空/真/假这类不可变值；列表、字典、函数不能当键。 |
| 迭代 | 可遍历：列表、文本（按字符）、字典（按键）、范围。 |
| 内存 | 脚本对象都放在固定堆里（固件默认 6 KB）；堆满报 E_OOM，不会崩溃。 |

## 硬限制

| 项目 | 上限 |
|---|---|
| 整数范围 | -268435456 .. 268435455（29 位） |
| 名字/常量 | 各 255 个 |
| 函数 | 255 个 |
| 局部变量/函数 | 255 个 |
| 实参/形参 | 各 255 个 |
| 列表元素/字典项 | 各 255 个（字面量编译期） |
| 调用层数 | 32 层（JM_MAX_FRAMES） |
| 值栈 | 512 槽（JM_STACK_SLOTS） |
| 脚本堆 | 固件 6 KB / 宿主默认 12 KB |
| 字节码 | 单个函数 <64 KB，整包 <64 KB |

## 内建 API

内建函数直接可用，不需要 `导入`（v0 也没有模块导入）。

| 名字 | id | 参数个数 | 说明 |
|---|---|---|---|
| `打印` | 0 | 0..255 | 把参数按显示形式输出，空格分隔，末尾换行；无返回值（空）。 |
| `文本` | 1 | 1..1 | 把任意值转成文本；文本原样返回。 |
| `整数` | 2 | 1..1 | 整数原样返回；数字文本按十进制解析；其他值报类型错误。 |
| `长度` | 3 | 1..1 | 文本按 UTF-8 字符数、列表按元素数、字典按键数、范围按元素数。 |
| `范围` | 4 | 1..3 | 范围(止) / 范围(起, 止) / 范围(起, 止, 步长)，左闭右开，步长不能为 0。 |
| `类型` | 5 | 1..1 | 返回类型名文本：整数 / 文本 / 列表 / 字典 / 范围 / 函数 / 内建 / 空 / 真 / 假 / 未定义。 |
| `总和` | 6 | 1..1 | 对列表或范围求和，只接受整数元素。 |
| `最大` | 7 | 1..1 | 列表或范围内的最大整数。 |
| `最小` | 8 | 1..1 | 列表或范围内的最小整数。 |
| `绝对值` | 9 | 1..1 | 整数的绝对值；超出 29 位范围报整数溢出。 |

## 编译期错误码

| 码 | 含义 |
|---|---|
| `E101` | 闭包暂不支持：内层函数读到了外层的局部变量 |
| `E102` | Micro Core v0 不支持小数（字面量带小数点或指数） |
| `E103` | 使用了 v0 不支持的关键字（类/继承/尝试/匹配等） |
| `E104` | 局部变量超过 255 个 |
| `E105` | 名字/常量/列表元素/字典项超过 255 个 |
| `E106` | 函数超过 255 个 |
| `E107` | 不支持参数默认值 |
| `E108` | 不支持属性访问「.」 |
| `E109` | 语法错误：缺少符号/换行/缩进错乱/字符串未闭合/中断继续位置不对 |
| `E110` | 整数超出 29 位范围（-268435456 .. 268435455） |
| `E111` | 单个函数或 .jmb 超过 64 KB |
| `E112` | v0 还没有模块导入 |
| `E114` | 实参超过 255 个 |

## 惯用法

### 用范围做计数循环

```砾
遍历 i 在 范围(0, 10):
    打印(i)
```

### 累加器

```砾
令 总和 = 0
遍历 x 在 列表:
    总和 += x
打印(总和)
```

### 字典当计数表

```砾
令 次数 = {}
遍历 x 在 范围(3):
    次数[x] = x * x
打印(次数)
```

### 文本拼接

```砾
令 n = 7
打印("n = " + 文本(n))
```

### 提前返回

```砾
函数 符号(x):
    如果 x > 0:
        返回 1
    如果 x < 0:
        返回 -1
    返回 0
```

### 共享数据放模块级

```砾
令 计数 = 0
函数 加一():
    计数 += 1
```

## 常见错误

### 小数不存在

错误写法：

```砾
令 x = 1.5
```

正确写法：

```砾
令 x = 3 / 2
令 余 = 3 % 2
```

原因：v0 只有整数，字面量小数直接编译失败（E102），真除法不整除也是运行错误。

### 缩进必须是 4 个半角空格

错误写法：

```砾
如果 真:
	打印(1)
```

正确写法：

```砾
如果 真:
    打印(1)
```

原因：Tab 与全角空格在缩进位置报 E109；全角标点只在代码里自动转半角。

### 函数不能读外层局部变量

错误写法：

```砾
函数 外层():
    令 x = 1
    函数 内层():
        返回 x
```

正确写法：

```砾
令 x = 1
函数 内层():
    返回 x
```

原因：v0 没有闭包（E101）；需要共享的数据放模块级 `令`。

### 没有类和属性访问

错误写法：

```砾
令 s = 对象.名字
```

正确写法：

```砾
令 s = 字典["名字"]
```

原因：`.` 属性访问与 `类/新建` 都被明确拒绝（E108/E103）；用字典加下标。

### 不要给未声明的名字赋值

错误写法：

```砾
计数 = 计数 + 1
```

正确写法：

```砾
令 计数 = 0
计数 = 计数 + 1
```

原因：读取未定义名字会报 E_NAME；先 `令` 再赋值。

### 列表/文本下标别越界

错误写法：

```砾
令 x = [1, 2][5]
```

正确写法：

```砾
令 x = [1, 2][长度([1, 2]) - 1]
```

原因：越界是运行错误 E_INDEX，不是返回空；负下标从 -1 开始。

## 可编译示例

### 你好（`hello`）

```砾
打印("你好，砾")
```

输出：`你好，砾`

### 递归斐波那契（`fib`）

```砾
函数 斐波(n):
    如果 n <= 1:
        返回 n
    返回 斐波(n - 1) + 斐波(n - 2)

打印(斐波(10))
```

输出：`55`

### 范围遍历求和（`sum-range`）

```砾
令 总和 = 0
遍历 i 在 范围(1, 6):
    总和 += i
打印(总和)
```

输出：`15`

### 字典计数（`dict-count`）

```砾
令 次数 = {"a": 1}
次数["b"] = 2
打印(次数["b"])
```

输出：`2`

### 文本拼接与内建（`text`）

```砾
令 n = 3
打印("n = " + 文本(n), 绝对值(-n))
```

输出：`n = 3 3`
