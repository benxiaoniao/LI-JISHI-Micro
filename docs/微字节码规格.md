# 砾 微字节码规格（JMB v1）

> 本文是 `micc`（编译器）与 `libjishim`（虚拟机）的**唯一契约**，也就是语言「砾」的字节码层。
> 两侧的指令编号由 `compiler/src/opcodes.rs` 生成，可用 `micc --emit-header` 导出 C 头文件比对。
> 文件后缀：`.jmb`；字节序：小端。

---

## 1. 值模型

一个值占 **4 字节**，低 3 位是标签，其余 29 位是载荷。

```
 31                      3   2   1   0
┌──────────────────────────┬───┬───┬───┐
│         载荷 (29 位)      │   │   │   │
└──────────────────────────┴───┴───┴───┘
```

| 标签 | 名称 | 载荷 |
|------|------|------|
| 0 | INT | 有符号 29 位整数，范围 `-268435456 .. 268435455` |
| 1 | NIL | 0（基石的「空」） |
| 2 | FALSE | 0 |
| 3 | TRUE | 0 |
| 4 | HEAP | 堆对象字节偏移 |
| 5 | FUNC | 代码对象下标 |
| 6 | BUILTIN | 内建函数编号 |
| 7 | UNDEF | 0（未初始化的槽位，读取即报错） |

堆对象头：

```c
typedef struct { uint16_t type; uint16_t rc; } JmObj;
```

| type | 名称 | 结构 |
|------|------|------|
| 1 | STR | `JmObj; u32 len; u8 data[]`（UTF-8，不可变） |
| 2 | LIST | `JmObj; u32 len; u32 cap; JmValue *items` |
| 3 | DICT | `JmObj; u32 len; u32 cap; JmEntry *entries`（插入序） |
| 4 | ITER | `JmObj; JmValue container; u32 idx; u32 kind` |
| 5 | RANGE | `JmObj; i32 start; i32 step; u32 len` |
| 6 | DEC | `JmObj; i32 raw`（Q12 定点，`raw = 值 × 4096`） |
| 7 | CLOSURE | `JmObj; u8 code_idx; u8 ncap; u16 pad; JmValue caps[ncap]`（捕获值快照） |

小数是 Q12 定点堆对象：值域约 `±524288`，精度 `1/4096`（0.000244）。整数与小数混算时，整数在 VM 内临时按 `×4096` 提升到 Q12（int64 中间量）。整数/整数的 `/` 仍要求整除，否则报 `E023`；**任一操作数是小数时 `/` 返回小数**，不再报 `E023`。

## 2. 文件格式

```
┌─────────────────────────┐
│ 头（12 字节）            │
├─────────────────────────┤
│ 常量表   nconsts × 8    │
├─────────────────────────┤
│ 名字表   nnames  × 2    │
├─────────────────────────┤
│ 代码表   ncodes  × 10   │
├─────────────────────────┤
│ 捕获表   (Σncap) × 2     │
├─────────────────────────┤
│ 类表     nclasses × 8    │
│ 字段名数组（每项 u8）     │
│ 方法对数组（每项 2×u8）   │
├─────────────────────────┤
│ 字符串池（常量与名字）    │
├─────────────────────────┤
│ 指令流（按 code 表引用）  │
└─────────────────────────┘
```

### 2.1 头

| 偏移 | 类型 | 字段 | 说明 |
|------|------|------|------|
| 0 | u32 | `magic` | `0x4A4D4231`（ASCII `JMB1`） |
| 4 | u8 | `version` | 4（JMB v4：类表；不再接受 v1/v2/v3） |
| 5 | u8 | `flags` | 保留，0 |
| 6 | u8 | `nconsts` | 常量数（≤255） |
| 7 | u8 | `nnames` | 名字数（≤255） |
| 8 | u8 | `ncodes` | 代码对象数（≤255） |
| 9 | u8 | `entry` | 入口代码下标，固定 0 |
| 10 | u8 | `nclasses` | 类数（≤255）；v3 及以前该字节为 0（保留） |
| 11 | u8 | `reserved` | 0 |

### 2.2 常量表（每项 8 字节）

| 偏移 | 类型 | 字段 |
|------|------|------|
| 0 | u8 | `kind`：0=INT，1=STR，2=NIL，3=TRUE，4=FALSE，5=DEC |
| 1 | u8 | 保留 |
| 2 | u16 | `len`（字符串字节数；其余为 0） |
| 4 | u32 | INT：有符号值；DEC：Q12 原始值（int32）；STR：字符串池偏移（绝对文件偏移）；其余为 0 |

INT 常量若超出 29 位范围、DEC 常量若超出 Q12 值域，**编译期报错**，不静默截断（字面量在编译期折算成 raw，取小数点后前 12 位并四舍五入）。

### 2.3 名字表（每项 2 字节）

| 偏移 | 类型 | 字段 |
|------|------|------|
| 0 | u16 | 名字字符串在文件中的绝对偏移（UTF-8，后接 `\0`） |

名字表同时用于：全局槽下标、代码对象名、内建函数名匹配。

### 2.4 代码表（每项 10 字节）

| 偏移 | 类型 | 字段 | 说明 |
|------|------|------|------|
| 0 | u16 | `off` | 指令流绝对文件偏移 |
| 2 | u16 | `len` | 指令流字节数 |
| 4 | u8 | `name_idx` | 名字表下标 |
| 5 | u8 | `nparams` | 形参个数（局部槽 0..nparams-1） |
| 6 | u8 | `nlocals` | 局部槽总数（≥ nparams，含捕获槽） |
| 7 | u8 | 保留 | 0 |
| 8 | u8 | `ncap` | 该函数的捕获数（0 表示普通函数） |
| 9 | u8 | 保留 | 0 |

`codes[0]` 是模块主代码：`nparams = 0`。

### 2.5 捕获表（每项 2 字节）

紧跟在代码表之后，按代码对象下标顺序排列：代码 `i` 的捕获项从「前面所有代码的 `ncap` 之和」处开始。每项：

| 偏移 | 类型 | 字段 | 说明 |
|------|------|------|------|
| 0 | u8 | `parent_slot` | 创建闭包时读取的**父帧**槽 |
| 1 | u8 | `child_slot` | 调用时填入的**子帧**槽；必须在 `[nparams, nlocals)` 内 |

捕获是**值快照**：`MAKE_CLOSURE` 执行时把父帧槽里的值复制进闭包对象并持有一份引用；之后父帧再改该槽不影响闭包。

### 2.6 类表（每条记录 8 字节）

紧跟在捕获表之后，`class_start = 捕获表结束`。`nclasses` 条定长记录连续排列，随后是全部类的字段名数组与 `(方法名, 代码对象)` 对数组；记录里的两个偏移都相对 `class_start`。

| 偏移 | 类型 | 字段 | 说明 |
|------|------|------|------|
| 0 | u8 | `name_idx` | 类名的名字表下标（`repr` 用） |
| 1 | u8 | `nfields` | 字段数（≤255），决定实例大小 |
| 2 | u8 | `nmethods` | 方法数（≤255） |
| 3 | u8 | `init_code` | 合成初始化代码对象下标（含字段默认值 + 用户 `初始化` 体） |
| 4 | u16 | `fields_off` | 字段名数组相对 `class_start` 的偏移；每项 u8 名字下标，按声明顺序 |
| 6 | u16 | `methods_off` | 方法对数组相对 `class_start` 的偏移；每项 `(u8 名字下标, u8 代码对象下标)` |

`初始化` 只存在于 `init_code` 里，**不进方法表**：`对象.初始化(...)` 会按 E037 报「没有这个方法」。字段名与方法名都用**名字表下标整数比较**（不做字符串比较）；同名两份（如字段与方法同名）由编译器在 E119 阶段拒绝。

加载器逐类校验：`name_idx < nnames`、`init_code < ncodes`、字段/方法数组不越过文件末尾、每个字段名与方法名下标 < `nnames`、每个方法代码下标 < `ncodes`。任一不符报 `E026`（`E_FILE`）。

### 2.7 尾部可选调试段

指令流之后**可以**追加一段调试信息；加载器从不检查这段，因此旧固件、`--strip-debug` 产物与带调试段的文件都能运行。

- `flags`（p5）的 **bit0 = 1** 表示「有调试段」；没有调试段时保持 0。
- 文件最后 6 字节是尾索引：`u16 total_len`（调试段长度，不含这 6 B）+ `u32` ASCII `DBG1`。
- 调试段从 `文件长度 - 6 - total_len` 开始，内部布局（多字节小端，段内偏移相对段起点）：

| 偏移 | 大小 | 字段 |
|---|---|---|
| 0 | 4 | magic `DBG1` |
| 4 | 1 | 版本，1 |
| 5 | 1 | flags：bit0 保留；bit1 = 每条行记录前带 1 B 文件标签（`nfiles > 1` 时置位） |
| 6 | 1 | `nfiles` |
| 7 | 1 | `ncodes`，必须等于头部 p8 |
| 8 | 2 | `files_off` |
| 10 | 2 | `codes_off` |
| 12 | 2 | `str_off`（文件名池） |
| 14 | 2 | 保留 0 |
| `files_off` | `2×nfiles` | 每项 `u16 name_off`，相对 `str_off` |
| `codes_off` | `6×ncodes` | 每项：`u16 entries_off`、`u16 nentries`、`u8 file_id`、`u8` 保留 |
| `str_off` | … | 文件名，UTF-8，`0` 结尾 |
| … | … | 行记录：varint 增量（见下） |

- 行记录首条为绝对偏移与绝对行号；其后为偏移增量与行号 zigzag 增量；`255` 表示后随一个 `u16`。偏移相对该代码对象指令流起点。
- `flags.bit1 = 1` 时，每条行记录前多 1 B 文件标签：`0` = 沿用上一条记录的文件，`k` = `file_id + 1`。这样模块代码对象里来自不同包顶层语句的行记录能各指各的文件；单文件（`nfiles = 1`）不置位，零额外开销。
- **体积上限只按剥离调试段后的长度计算**；调试段本身计入文件总长，但超过 64 KB 报 `E131`，可用 `--strip-debug` 剥离。调试段与指令流重叠、尾索引不合法或条目越界时，全部按「无调试信息」处理，不阻止运行。
- `micc --strip-debug` 去掉整段并把 `flags.bit0` 清零；其余字节与不带调试段的旧文件一致。

详细设计与实测开销见 [JMB调试表设计.md](JMB调试表设计.md)。

## 3. 指令格式

变长编码：

| 形态 | 长度 | 说明 |
|------|------|------|
| A | 1 字节 | 只有操作码 |
| B | 2 字节 | 操作码 + u8 |
| C | 3 字节 | 操作码 + u16（跳转目标，**指令流内绝对字节偏移**） |

### 3.1 操作码表

| 码 | 名称 | 形态 | 操作数 | 栈效果 |
|----|------|------|--------|--------|
| 0 | `HALT` | A | — | 结束 |
| 1 | `CONST` | B | 常量下标 | `→ v` |
| 2 | `LOAD_LOCAL` | B | 局部槽 | `→ v` |
| 3 | `STORE_LOCAL` | B | 局部槽 | `v →` |
| 4 | `LOAD_GLOBAL` | B | 名字下标 | `→ v` |
| 5 | `STORE_GLOBAL` | B | 名字下标 | `v →` |
| 6 | `POP` | A | — | `v →` |
| 7 | `DUP` | A | — | `x → x x` |
| 8 | `SWAP` | A | — | `a b → b a` |
| 9 | `BINOP` | B | 见 3.2 | `l r → 结果` |
| 10 | `NEG` | A | — | `v → -v` |
| 11 | `NOT` | A | — | `v → 非 v` |
| 12 | `CMP` | B | 见 3.3 | `l r → 布尔` |
| 13 | `JUMP` | C | 目标 | — |
| 14 | `JUMP_IF_FALSE` | C | 目标 | `v →`（假则跳） |
| 15 | `JUMP_IF_TRUE` | C | 目标 | `v →`（真则跳） |
| 16 | `JUMP_IF_FALSE_OR_POP` | C | 目标 | `v → v?`（假则保留并跳，真则弹出） |
| 17 | `JUMP_IF_TRUE_OR_POP` | C | 目标 | `v → v?` |
| 18 | `CALL` | B | 位置实参个数 | `f a1..an → 结果` |
| 19 | `RETURN` | A | — | `v →`（返回） |
| 20 | `BUILD_LIST` | B | 元素个数 | `x1..xn → 列表` |
| 21 | `BUILD_DICT` | B | 键值对数 | `k1 v1..kn vn → 字典` |
| 22 | `GET_ITEM` | A | — | `obj idx → v` |
| 23 | `SET_ITEM` | A | — | `obj idx v →` |
| 24 | `GET_ITER` | A | — | `可迭代 → 迭代器` |
| 25 | `FOR_ITER` | C | 耗尽目标 | `迭代器 → 迭代器 元素`；耗尽则弹出迭代器并跳转 |
| 26 | `MAKE_FUNCTION` | B | 代码下标 | `→ 函数` |
| 27 | `IMPORT` | B | 名字下标 | 保留（JM7 起启用） |
| 28 | `MAKE_CLOSURE` | B | 代码下标 | `→ 闭包`；按该代码对象的捕获表从当前帧取值 |
| 29 | `TRY` | C | 处理器偏移 | 压入一层尝试记录：`{帧, 当前 sp, handler}`；嵌套超过 8 层报 `E028` |
| 30 | `TRY_END` | A | — | 弹出最内层尝试记录；栈空或帧不匹配报 `E029` |
| 31 | `THROW` | A | — | `v →`（不返回）；无记录则报 `E027`，否则展开并跳到 handler |
| 32 | `NEW_INSTANCE` | B | 类下标 | `→ 实例`；字段全部先填 `未定义` |
| 33 | `GET_FIELD` | B | 字段名下标 | `实例 → v`；非实例报 `E036`，没有该字段报 `E035` |
| 34 | `SET_FIELD` | B | 字段名下标 | `实例 v →`；失败语义同 `GET_FIELD`；写入前释放旧值 |
| 35 | `CALL_METHOD` | B+B | 方法名下标, 实参个数 | `实例 a1..an → 结果`；接收者占方法的槽 0 |
| 36 | `CALL_INIT` | B+B | 类下标, 实参个数 | `实例 a1..an → 实例`；调用该类的 `init_code` |
| 37 | `RETURN_METHOD` | A | — | `v →`（返回）；释放槽 1..nlocals-1 与接收者槽，返回值写回槽 0，`sp = base + 1` |

### 3.2 `BINOP` 子码

| 码 | 运算 | 整数行为 | 含小数操作数时 |
|----|------|----------|----------------|
| 0 | `+` | 加（文本/列表为拼接） | Q12 相加，结果小数 |
| 1 | `-` | 减 | Q12 相减，结果小数 |
| 2 | `*` | 乘（整数溢出报 E009） | `round(A*B/4096)`，结果小数 |
| 3 | `/` | 真除法；结果必须是整数，否则 E023 | `round(A*4096/B)`，结果小数，**不报 E023** |
| 4 | `//` | 向下取整除法 | 向下取整，结果整数 |
| 5 | `%` | 取余，符号跟除数（与 JISHI/Python 一致） | Q12 余数，结果小数 |
| 6 | `**` | 幂（负指数或溢出报 E009/E024） | 指数须为整数，结果小数 |

舍入统一为「四舍五入、远离零」。小数结果超出 Q12 值域报 `E009`。不新增操作码：`BINOP`/`CMP`/`NEG` 直接按值类型分派。

### 3.3 `CMP` 子码

`0 ==`、`1 !=`、`2 <`、`3 >`、`4 <=`、`5 >=`。

## 4. 调用约定

栈布局：`[被调用值] [实参1] ... [实参n]`。

- **用户函数**（`FUNC`）：帧基址 = 被调用值位置 + 1；形参正好占用局部槽 `0..nparams-1`；再压入 `nlocals-nparams` 个 `UNDEF`。
- **闭包**（`HEAP` + `CLOSURE`）：同上建立帧，然后把闭包的 `caps[k]` 写入捕获表指定的 `child_slot`（帧自己再持有一份引用）。闭包的捕获数必须与代码对象的 `ncap` 一致。
- 实参个数必须等于形参个数，否则 `E012`。
- `RETURN`：把返回值写回被调用值位置，释放该帧的局部槽，`sp = 基址 - 1 + 1`。
- **内建函数**（`BUILTIN`）：由 C 侧直接取栈上实参计算，释放实参，结果写回被调用值位置。
- **方法**（`CALL_METHOD`）：栈上是 `[接收者] [实参...]`，**接收者就是被调用值**，因此帧基址 = 接收者槽 = 槽 0（`本`）；形参从槽 1 开始，`nparams = 实参个数 + 1`。方法代码对象没有捕获表（捕获在调用它的闭包里完成）。
- **构造**（`CALL_INIT`）：同方法布局，但被调用代码由类记录的 `init_code` 指定；实参个数必须等于 `init_code.nparams - 1`。返回时把接收者实例写回槽 0，所以 `新建` 表达式的结果就是实例。
- **`RETURN_METHOD`**：与 `RETURN` 的区别只在收尾——保留槽 0 的返回值，释放其余局部槽与接收者槽，`sp = base + 1`。

模块主代码：帧基址 = 0，入口时压入 `nlocals` 个 `UNDEF`。

### 4.1 异常与栈展开

`TRY` 记录进入时的帧下标与该帧的操作数栈深度 `sp`。`THROW` 的计算：

1. 弹出抛出值（持有 1 份引用）。
2. 若尝试栈为空：把值渲染进 **64 B 显示缓冲（60 B 正文 + 3 B「…」 + NUL）**，超出时截断并以「…」结尾，释放值，报 `E027`
   `未捕获的异常：<值>`；固件沿用既有 `[砾] 运行失败: ` 前缀。
3. 否则弹出最内层记录，把 `sp` 截回记录里的深度，逐项 `release` 被丢弃的栈项
   （操作数临时值、被调用值、以及被展开帧的形参/局部槽/闭包捕获槽都在这里，各占一项），
   并把帧指针退到记录所属帧。
4. 把抛出值压回处理器所在帧的栈顶，`ip` 跳到记录里的 handler。

handler 是编译器生成的绑定块：`STORE_LOCAL 槽`（具名 `捕获 名字`，模块顶层为
`STORE_GLOBAL`）或 `POP`（匿名 `捕获:`），随后进入捕获体。

编译器在每个 `返回` / `中断` / `继续` 离开 `尝试` 的出口前都会先发 `TRY_END`；
正常走完 `尝试` 体也发 `TRY_END` 再跳过长捕获体。只有显式 `THROW` 进入 handler：
`E007` 除零、`E017` 堆耗尽等 VM 故障，以及原生函数返回的 `E030/E031/E033`，
直接终止 `jm_run`，`捕获` 无法拦截。

| E005 | 名字下标越界 |
| E006 | 局部槽越界 / 读取未初始化局部 |
| E007 | 除以零 |
| E008 | 取模零 |
| E009 | 整数或小数溢出 |
| E010 | 类型不支持该运算 |
| E011 | 不是可调用对象 |
| E012 | 实参个数不符 |
| E013 | 下标类型错误 |
| E014 | 下标越界 / 键不存在 |
| E015 | 不可迭代 |
| E016 | 迭代器类型错误 |
| E017 | 堆内存耗尽 |
| E018 | 对象类型错误 |
| E019 | 字典键不可用 |
| E020 | 代码对象越界 |
| E021 | 帧深度超限 |
| E022 | 不支持的指令 |

## 6. 内存与所有权

- 堆是**静态字节数组**（`JM_HEAP_SIZE`），块分配器，首次适配 + 合并。
- 对象用**引用计数**：栈槽、局部槽、全局槽、容器元素、闭包捕获各持有一份引用。
- 闭包是堆对象：创建时对每个捕获值 `retain`，闭包释放时逐个 `release`；调用时捕获槽在帧内再持有一份引用。
- **闭包/容器/实例可以形成环**（例如闭包捕获了包含它自己的列表，或 `本.自己 = 本`）。引用计数不会归零，这块堆**永久不回收**：当前**没有 GC**，接受环引用泄漏（v0 不做标记清扫）。反复创建这类环会逐步耗尽堆，最终运行期报 `E017`（`E_OOM`），不会崩溃。
- 实例是堆对象：`JmObj(4 B) + class_idx(1 B) + nfields(1 B) + 保留(2 B) + fields[nfields]`，含块头共 `16 + 4n` 字节；字段固定布局，不扩容。
- 字符串不可变；列表/字典增长时重新分配底层数组。

## 7. 版本策略

- `.jmb` 的 `version` 只在**不兼容**时递增：v2 加入捕获表，v3 加入异常指令，v4 加入类表与 6 条实例/方法指令（加载器拒收旧版本以强制重编）。
- 新增操作码**只能追加**，不复用已废弃编号。
- 加载器遇到未知 `version` 或未知操作码，报 `E022`，不猜测执行。
