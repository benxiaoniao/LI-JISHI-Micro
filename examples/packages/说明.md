# 包示例（H4 最小切分）

用途：`tools/test-packages.ps1` 第 17 个用例会打包这里的 `应用`，确认仓库内的示例包一直可用；同时也当作 `docs/包规范.md` 的可运行样例。

- `工具/`：被依赖的源码包。`砾包.toml` 里用 `[导出] 名字 = ["加一", "问候"]` 声明跨包可见的名字；`令 内部 = 99` 没有导出，跨包引用会报 E128。
- `应用/`：入口包。`[依赖] 工具 = { 路径 = "../工具", 版本 = "^0.1.0" }`，源码里用 `工具.加一(...)` / `工具.问候(...)` 调用。

用法（在仓库根目录）：

```
micc pack --目录 examples/packages/应用 -o build/packages-示例.jmb
build\jmrun.exe build\packages-示例.jmb
```

预期输出：

```
你好，砾
42
```

离线流程：先在 `examples/packages/应用` 里跑一次 `micc install`（生成 `.砾/锁.toml` 与 `.砾/包`），之后 `micc pack --目录 examples/packages/应用 --离线` 只读锁与缓存，不再看 `../工具`。`.砾/包/` 已在 `.gitignore` 里忽略，`.砾/锁.toml` 应入库。
