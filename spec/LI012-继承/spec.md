# LI012 单继承 · 规格（已批准，2026-11-11 实施完成）

## 1. 目标与范围

给 `类` 加**单继承**：`类 子 继承 父:`。父类字段与方法被子类继承，方法可覆写，构造沿父链自动执行。这是路径图阶段 D 的第一项，也是唯一确定要升 JMB 类表结构的一段。

**做**：

- 语法 `类 子 继承 父:`（父类可写在后，不要求先声明）。
- 字段继承（父字段在前、子字段在后，落成扁平布局）、方法继承与覆写、构造链。
- JMB v4 → **v5**：类记录 8 B → 10 B，新增 `parent_idx`。
- 运行期成员查找沿父链；`CALL_INIT` 允许父构造作用于子实例。
- 示例、错误用例、全套实测、语言卡/路径图/字节码规格同步。

**不做**（留给后续）：

- `超`（LI013）、`最终`（LI014）、多继承、虚表、接口、抽象方法、跨包继承、编译期静态分派优化。
- 不改 Native ABI，不改调试段格式，不引入 GC。

## 2. 语法与语义（已定）

### 2.1 语法

```
类 子 继承 父:
    令 新字段 = 默认值
    函数 初始化(参数): ...
    函数 新方法(...): ...
```

`继承` 由 `Kw::Unsupported` 提升为真实关键字 `Kw::Inherit`。`最终` / `用` / `超` 保持不支持（E103）。

### 2.2 继承规则

- 父类必须是**同一模块**（单文件或 pack 合并后同一编译单元）里已声明的类；按名字解析，**不要求父类先写**。
- 拒绝：父类未定义、继承自己、继承成环、子类重定义父类字段、子类字段与父类方法重名、子类方法与父类字段重名。
- 方法同名 = **覆写**（允许，签名不校验）。
- 字段一律**不覆写**；字段名沿整条父链唯一。
- 字段总数为父链累加后 ≤ 255（E105）；类数仍 ≤ 255。
- 父类 `初始化` 若带形参，则**不允许被继承**（LI012 没有 `超`，无法自动传参）→ E140。父类没有 `初始化` 或它零形参时正常。

### 2.3 字段布局与查找

- 类表里每个类存**扁平字段名数组**：`父类扁平字段 ++ 本类字段`。因此 `GET_FIELD`/`SET_FIELD` 仍是单层名字查找，VM 字段查找逻辑不变。
- 实例 `nfields` = 扁平字段总数；`新建` 按它分配。
- 父类初始化代码里的字段下标，与子类扁平数组的前缀完全一致，所以父初始化作用在子实例上仍写到正确槽位。

### 2.4 方法查找与覆写

- 类表只存**本类**方法；运行期从实例的类开始，沿 `parent_idx` 上溯找方法名，先命中者生效 → 子类同名方法自然覆写父类。
- 父类方法里的 `本.方法(...)` 走运行期派发，因此会调到子类覆写版本（单继承下的“虚分派”）。

### 2.5 构造链

- 子类合成初始化代码顺序：
  1. `LOAD_LOCAL 0` + `CALL_INIT 父类 0` + `POP`（父类初始化跑完再返回）；
  2. 本类字段默认值（按声明顺序，禁止引用 `本`）；
  3. 本类 `初始化` 方法体；
  4. `返回 本`。
- 无父类时跳过第 1 步。多级继承逐级递归，顺序为：最老祖先的字段默认值 → … → 本类字段默认值 → 本类 `初始化` 体。
- `初始化` 仍禁止显式 `返回`（E120）；`新建 子(...)` 的实参只对子类 `初始化` 校验。

### 2.6 打印

实例打印沿用现有格式：`类名{字段: 值, ...}`，字段顺序即扁平顺序（父字段在前）。

## 3. JMB v5

- `VERSION = 5`；loader 只收 `p[4] == 5`，旧文件报 E_FILE「需要 JMB v5」。
- 类记录 `CLASS_REC = 10`：

| 偏移 | 类型 | 字段 |
|---|---|---|
| 0 | u8 | `name_idx` |
| 1 | u8 | `nfields`（**含继承**的扁平总数） |
| 2 | u8 | `nmethods`（仅本类） |
| 3 | u8 | `init_code` |
| 4 | u16 | `fields_off`（相对 `class_start`） |
| 6 | u16 | `methods_off`（相对 `class_start`） |
| 8 | u8 | `parent_idx`（255 = 无父类） |
| 9 | u8 | 保留 0 |

- 字段名数组、方法对数组、字符串池、指令流布局不变；`fields_start` / `methods_start` 计算改用 10 B 步长。
- loader 新增校验：`parent_idx == 255 || parent_idx < nclasses`、`parent_idx != 自己`、沿父链上溯不超过 `nclasses` 步（防环）、每步下标 < `nclasses`。

## 7. 风险与取舍

- **Flash**：VM 方法链查找与 CALL_INIT 祖先校验各多一个循环，预计几十字节；以固件实测为准。
- **构造语义**：父 `初始化` 带参即拒绝，是 LI012 的明确限制；LI013 `超` 再放开。
- **字段扁平化**：类表体积随继承深度×字段数增长（每字段每类 1 B），换取 VM 字段查找零改动；在 255 字段上限内可接受。
- **跨包继承**：不开放；父类不在本模块即 E140，跨包类型导出仍按 LI016 另行设计。
